# Burger Shop

一款面向 Android 的单人 3D 休闲经营游戏。玩家经营汉堡店，完成制作、送餐、收款、升级和自动化循环。

## 技术基线

- Unity 6.3 LTS (`6000.3.23f1`)
- Universal Render Pipeline 17.3
- Input System 1.20
- Android Build Support
- 目标画面：竖屏

## 核心循环

`接单 → 制作汉堡 → 送餐 → 收金币 → 升级设备/员工 → 提高效率 → 解锁新区域`
