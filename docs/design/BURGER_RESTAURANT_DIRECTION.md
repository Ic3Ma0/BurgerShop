# BurgerShop 产品与视觉方向

2026-09-14。本文件把用户的产品方向转成具体取舍。玩法建议不构成实施授权；是否已进入开发以对应 spec 和当前源码为准。

## 当前判断

这是一款靠走动经营、即时收钱、扩店和布置获得成长感的手机汉堡餐厅游戏。应该让玩家看得懂“谁在等、哪里缺、下一步能做什么”，用更好的生意与店铺变化吸引继续玩，而不靠强制停工或重复劳动拖长时间。

本地已具备堂食与清桌、可乐、蓝盒汽车订单、红盒骑手产线、纸袋线、员工自动化、店铺里程碑与星级、20 级属性线和设施自由摆放。应先提高这些机制的完整度与辨识度，再扩展新循环。零件当前只收集，未经新 spec 不增加消费。

事实来源：FacilityCatalog 的 15 类商品；SessionGoalTracker 的里程碑/星星和循环等级；PlayerBoost/StaffBoost；048 的独立外卖加工机。GAME_CORE.md §8 的“Rank 6 封顶”是旧快照：当前代码 IsMaxRank=false，已有循环等级，不能继续当作现状提出重复开发。

## 新增玩法的分析要求

依据用户 2026-09-14 的补充：本作的成长主线是从小店卖汉堡、赚钱升级，到扩店、增加服务方式、雇人分工，再经营更复杂的餐厅。新内容需要让玩家理解“我的店为什么需要它”，购买后确实感到经营方式发生变化，并能期待下一步。不能只罗列现实餐厅里存在的房间和设备，也不能靠增加琐事维持在线时长。

### 先从玩家处境推导功能

每个新玩法的规格必须把下面的因果关系说清，深度与影响范围相称；文案、美术或局部修复不必套整套分析。

| 分析点 | 必须回答的问题 |
|---|---|
| 玩家当前处境 | 在哪个经营阶段，已经会什么、忙什么、缺什么？来自实际操作、代码推导还是尚待验证的假设？ |
| 现实餐厅逻辑 | 谁产生需求、谁提供服务、货物/顾客/钱如何流转？地点、动线和设备用途是否看得懂？可简化现实操作，但不能丢掉因果。现实中存在不等于值得做成玩法。 |
| 独特体验 | 新增了什么决策、动作或经营问题？与堂食、清桌、打包、外卖、可乐、自动化逐项比较；只是换商品、搬得更远或再擦一个表面，应归为内容/规模变化，不能宣称为新玩法。 |
| 解锁时机 | 玩家为什么现在想要它？既有循环是否已学会、开始出现适合解决的瓶颈？前置能否用已开放内容完成？不能依赖尚未解锁的功能才能解锁自己。 |
| 三段体验 | 解锁前如何预告用途和差额；解锁后的首次操作如何快速体会价值；熟悉后有什么布局、分工或效率选择，避免长期重复教学期的杂务。 |
| 与旧店的关系 | 新内容改变哪段供需、运输、服务或收款？旧设施和升级为什么仍值得使用？不能一条高收益新线让整个旧店失去价值。 |
| 下一个期待 | 这次升级有哪些可见、可感知的改善？下一项具体目标是什么、还有多远？不能只显示未知锁头，也不能一次性倾倒全部玩法。 |
| 代价与替代 | 占多少空间、注意力、操作和金币？能否通过改善已有功能解决同一问题？不能用人为故障、罚款或收费去抵消一个本来没有价值的系统。 |

例如自动化的价值应是让玩家从反复搬运转向布置与分工；如果雇人后只剩观看，就需要检查下一项可推进目标。卫生间虽然符合题材，但如果只增加反复清洁，并不自动获得玩法价值，应检查它与客人服务过程的关系。以上是分析方法，不是本轮新增规则或对既有功能的验收结论。

### 金币与等级一起核算，分别承担职责

- 金币承担经营取舍：当前应该扩空间、买设备、升级还是雇人。等级组织学习与解锁顺序。核对当前里程碑、星星及循环等级实现，不凭概念重新建立另一套等级制度。
- 报价必须看“解锁后能正常营业”的完整投入：地块、必要设备、必要升级、人员，以及实际存在的经营费用。不要用低廉地价掩盖后续门槛，也不要为了消耗金币擅自添加租金、原料费或维护费。
- 使用真正入账的金币速度，区分理论产能、已售未收和已收现金；计入客流、生产、搬运、收银与空间瓶颈。新增机器不必然等于收入翻倍。
- 基础估算：`T_cash ≈ max(0, 目标总投入 − 可用余额) / 有效净入账速度`。单位保持金币和时间一致；收入随阶段变化时分段估算。里程碑与攒钱可能同时推进，不能机械相加；首次完成整段解锁需要实际观察。
- 同时比较改前/改后的下一次小升级、下一项玩法解锁和更后续目标。分别检查刚达到解锁条件的新玩家、正常经营玩家、拥有多台机器与自动化的玩家；若受离线收益或增益影响，也纳入适用情景。不能只用满配收入给刚解锁的玩家定价。
- 检查两端：赚钱过快、回本过短导致连续买空内容；投入过大、回报不明显导致长时间无进展。期望是升级后能感到变强，同时仍有可理解、可推进的目标，不是把所有阶段都拖慢。
- 把数值区间标清为“当前代码值 / 估算与假设 / 实测 / 建议目标”。`GAME_CORE.md` 的 T(n) 建议带不是已经验证的体验结论；没有有效收入数据，就列明缺口与局部测量方法，不编实际耗时。

### 提案与验收

后续玩法提案提供“玩家处境 → 为什么选这项而非替代方案 → 解锁前/首次/熟悉后的体验 → 完整投入与收入影响 → 接续目标 → 如何验证”。必要时明确建议暂不做，不用候选数量证明产品工作量。

规格写出可观察的通过/失败条件：玩家能否理解用途与下个目标；第一次体验是否清楚；学习后是否仍有选择；旧店是否仍有价值；攒钱是否落在本次规格的目标范围；有没有只能干等的阶段。代码测试能验证规则，局部试玩能发现节奏问题，长期留存改善需要后续玩家数据，三者不能混称为已证明。

本节约束设计方法，不新增玩法、收费或价格，不扩大既有 spec 的授权。沿用节奏契约 I1–I8，玩家可以自然离开；不把“想继续”做成“不能停”。

## 筛选新玩法

依据 GAME_CORE.md §5、§6：必须有新动作或新决策，且影响既有经营。每个候选都要说明玩家做什么、改变什么、可以如何自动化、有何退路。再加一条不同颜色的打包线、更长的搬运路程、重复清理另一个表面，不足以构成新玩法。

| 优先顺序 / 候选 | 新决策 | 对现有经营的作用 | 边界与同质化检查 |
|---|---|---|---|
| 1 午间客流与人员调度 | 营业前选择重点服务堂食、饮品或车窗，并把现有员工调往对应岗位 | 让已经购买的产能和自由布局变成有目的的经营选择 | 不再新增一个搬运工种；可不参加，无倒计时失败惩罚，常规订单继续 |
| 2 家庭团客与拼桌 | 根据人数选择拼桌或安排等候，留出入座通道 | 改变现有桌型价值、顾客入座与翻台决策 | 不是同一顾客要求更多汉堡；必要核心是多人一起入座，不用高倍率价格伪装新玩法 |
| 3 卫生间与座位保留 | 顾客暂离时保留座位，玩家管理可用隔间和清洁优先级 | 延展“进店—就座—离座—回座—离店”的完整动线，让服务设施影响堂食接待 | 用户提出的合理房间，但若只做“脏了擦一下”会重复清桌，应放在团客/座位机制后；不因厕所脏而锁死全店，不收如厕费 |
| 4 招牌菜单与推荐牌 | 看设备余量，选择今天推广哪种已有商品 | 改变订单构成，让可乐区或闲置产能被使用 | 不是新增相似产品线；先测基础供需，再决定推广幅度，不在未实测时承诺收益 |

状态说明：上表保留最初提出时的候选比较，不代表已确认开发顺序。卫生间已由 BS-SPEC-053 实现（`RestroomExpansion`），后续应复盘实际价值，不能再次作为尚未实现的新功能提案。

第一推荐是人员调度：现有工位已多，玩家目前能摆设备，却缺少“这波生意我怎么接”的轻决策。卫生间可以成为有用途的扩建，但不应仅为了填空地而增加清洁杂务。

暂不推荐：再加颜色包装、强制机器故障、额外货币、强制等待广告、每日不登录惩罚。主动可选的经营活动比周期性惩罚更适合当前轻松风格。

## 视觉语言

- 轮廓先于细节：正常游戏镜头下，不看字也能识别烤台、饮料机、打包台、收银台。
- 材质：不锈钢、奶油白面板、番茄红品牌点缀、深灰结构；蓝盒工位保留蓝色。避免用荧光色覆盖整台设备。
- 比例：工作台在人物腰部附近，饮料机机头略高；不再把升级等同于整体巨幅放大或叠烟囱。
- 升级：单烤区到多烤区、单嘴到多嘴、普通柜台到带小菜单牌的柜台。颜色变化辅助结构变化。
- 人物：厨师帽和白制服识别玩家，员工按现有身份配色，顾客用便装；手脚参与移动，碰撞与寻路仍由原组件负责。
- 货币：世界钱堆、HUD 和收钱飞行统一绿色纸币；图案纹理使用 mipmap，避免远处细线闪动。
- 手机阅读：少量清晰图案与材质优于微小文字、密集管线和装饰灯；工作状态优先于装饰。

## 下一步的产品验收顺序

先确认当前正常镜头中的设备辨识、人物移动、纸币收取以及菜单信息；再观察玩家的实际缺货/排队/空闲工位，选一个新决策做小规格。任何玩法试验都先约定成功标准、退出路径和价格依据，不直接套用新货币或固定收益。


## 扩建的空间组织（058 起）

每次扩建要让店铺获得一项看得懂的能力，并与既有交通连接。主厅承担接待和堂食，东侧饮品与座席，北侧加工与骑手，南侧临主路车窗，西侧外带操作；卫生间和员工办公室属于辅助服务。058 先统一预告、购地入口及装修，保留现有土地尺寸和玩家布置。

以后提新玩法时，先画顾客、员工、货物三条路线，说明哪一条既有路线会改善、空间为什么值得买，再决定是否需要新地块。服务入口应接顾客动线，工作入口应接员工通道；不要为了塞新系统把队伍挤在主门，或让顾客穿加工区去吃饭。地板材质、墙面和门头延续同一餐厅风格，区域用少量色差区分。成长感来自真实服务能力和可见空间变化，不靠机械增加同款房间。

购地预告需讲清区域用途、实际解锁条件、剩余地价及可营业的必要设备投入。当前土地不等于无限扩建；未来功能的地块、价格与解锁仍分别写入对应规格，不能预先制造收费口或永久空房间。
