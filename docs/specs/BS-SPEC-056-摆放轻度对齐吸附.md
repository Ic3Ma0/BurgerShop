# BS-SPEC-056 摆放轻度对齐吸附

用户需求：设施靠近并排/对齐时自动精确对齐，预览后Done确认；擦边经过或刻意错开不强拉。

仅修改摆放辅助，不改价格、设施数量、存档schema、原有碰撞/通路规则。

规则集中PlacementAlignment：邻近设施边缘间距不超过1.4世界单位、角度差不超过6度（180度平行等价但保持朝向），边线/中心线误差不超过0.22，且原始拖拽点在0.06范围停稳0.25秒后，才尝试吸附。支持相同或不同尺寸、已旋转设施，以占地框的正面/背面/中心线对齐；接近相邻边时保持0.12间隙，不能重叠。一次仅选一个近邻，避免交叉牵引。

候选姿势通过原CanPlace完整校验后才应用；不能吸入墙外、未购买空间、阻断工作点/通路。失败保留原始自由摆放姿势。

吸附后显示青色对齐线和Aligned提示；继续拖动超过0.5即脱开。手动旋转立即解除；碰到UI时停止新增吸附，Done只提交已显示姿势。手机松手仍保留预览，不修改为自动购买。移动已有与新购物品共用。

验收：小偏差+停稳可对齐；斜向近角自动修正；远距离/角差过大/快速擦过不吸；拖出可脱开；非法候选不吸；UI不会拖走/吸走预览；Done保存精确预览。定向EditMode及本地画面核对，Android本轮不做。
