# BS-SPEC-055：点击设施升级

- 状态：已实现，本地定向验证通过；手机验收待统一安排
- 用户确认：直接点设施打开详情卡；商城已有设施也可进入，靠近自动取餐等继续保留。
- 前置：BS-SPEC-043 自由摆放、BS-SPEC-054 商城实体图。

## 范围与流程

轻点已建成的机器、桌椅、柜台等，打开设施详情卡。卡片展示实体图、名称、当前等级、升级前后效果、绿色纸币价格，以及 Upgrade、Move、Close。无需走到设施旁或站圈等待。移动继续使用既有旋转、拖放、Done 流程。

机器、柜台、打包设备读取现有升级规则；餐桌保留一次性三选一，直接展示三个款式与收益，点击所选款式的升级按钮即购买。没有升级规则的设施只展示用途与移动入口。已用完现有升级选项时展示当前效果和移动入口，不新增梯子或 MAX 进度条。

详情卡暂停经营与相机跟随，关闭后恢复打开前状态；转入摆放时保持暂停，Done / Cancel / Close 沿用商城恢复逻辑。购买后卡片更新当前等级和下一步效果，显示简短成功反馈。没有二次确认。

## 经济、兼容与输入

- 所有升级价格、产能、收益、星星、等级上限保持现有配置。只移除站定触发升级的交互等待；T(n) 的攒钱部分不变。
- 旧餐桌已投入部分金币抵扣本次费用；已付满待选款的存档免费选款。原存档字段继续使用，不新增持久化字段。
- 钱不足显示准确差额，不扣钱；重复事件、过期等级或餐桌已选款不得重复扣钱。
- 点按按下与抬起需落在同一设施；滑动、长按、摇杆、UI 按钮、多指操作不触发。商城/摆放中沿用原输入。
- 移除已建设施旧升级圈与靠近自动弹出的升级 UI；新地块、新建设施的购买与引导不在本次改动范围。

## 验收

1. SampleScene 轻点设施打开详情，移动或使用摇杆不误开；近距离站旧升级点不会扣钱。
2. 汉堡机、可乐机、柜台、打包设备经按钮按实际配置升级；不足与重复操作无错误扣款。
3. 餐桌直接三选一；部分投币只补差额，已付满免费选款，款式与收益保存。
4. 商城已有设施进入同一详情，Move 接续原摆放；关闭详情及摆放后经营恢复。
5. 横屏与手机竖屏布局可读、可操作，实体图可见。EditMode 定向验证及本地画面检查；手机实测留待统一验收。
