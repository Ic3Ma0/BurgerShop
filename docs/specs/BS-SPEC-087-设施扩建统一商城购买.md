# BS-SPEC-087 设施扩建统一商城购买

用户要求取消截图中的站圈投入金币购买方式，设施与扩建统一从商城获取。

- 所有设施/扩建购买圈及其悬浮模型、金额指引不再显示，站在旧位置不扣款。
- 商城「购买」与「空间扩建」保留原定价格、解锁条件、摆放和星奖励。旧档已建空间/设施及部分投入金额保留，在商城抵扣。
- 收银、取货、清洁等操作点不是购买入口，保留；人物点击升级与员工雇用不在本次设施购买迁移范围。

## 技术边界与方案审查

- 归属与复用：沿用 FacilityUnlockZone.SetStoreOnly，在 ShopExpansion / BagLine 生产创建入口立即应用；卫生间已采用该模式。不删除承担存档投资额度的组件。
- 状态归属：设施持有原投资与完成状态，商城调用既有交易入口；不新增状态所有者或存档字段。
- 依赖方向：商城调用经营购买 API，场景圈仅退出显示和站圈交易，不反向驱动商城。
- 兼容与失败：读档、解锁刷新不重新显示购买圈；已投入金额保持、余额不足不购买；已有解锁回调照常执行。
- 自动防线：隔离 SampleScene 验证所有设施购买圈隐藏且不可扣款、旧投入保留、商城补款建成、重复购买不扣款；运行 check-boundaries.sh。

## 验收

1. 截图位置无 WING 金额箭头、购买圈和悬浮购买模型。
2. 升级、读档、建成侧翼/外卖区后，新旧设施购买圈都不出现。
3. 旧投入只从应付金额中抵扣一次，商城购买正常奖励星，重复点击不重复消费。
