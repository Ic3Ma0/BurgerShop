# BS-SPEC-073：开车单车辆生成

- 版本：v1.1
- 状态：**已完成**（刷车门槛由 [074](BS-SPEC-074-开车窗口已开即刷车.md) 修正）
- 开发时基线（历史）：本地 `main` + 未提交 057–072；开车循环沿用 022/046；等级表见 069；房间门槛见 064；点击晋级见 070
- 优先级：Rank 6 任务是 Complete a drive-thru order，玩家能买到打包/开车装置，但车不来，里程碑无法完成
- 前置：022 装箱+得来速；046 南侧汽车服务区；064 汽车厢 Lv.5；069 Rank 6 = `CarOrder`；070 补星后点击 Upgrade
- 用户已确认：不改价、不加新车型、不改 069 两张起步桌、不改 071 室内 Walk（除非车道本身坏了再补车道路点）；柜台叠高/烤台上限归 072，本文件不碰
- 产品建议或关键未定项：无。车在**车道已建成且 Rank ≥ 6**（`CarOrder` 已开放）后出现，不提前到 Rank 5

## 目标与范围

Rank 5 Upgrade 打开南侧汽车厢和开车柜台购买资格。Rank 6 要完成一单开车。试玩里玩家买了打包/开车装置，窗口和包装柜能看见，但车道上没有车，无法交货，Upgrade 永远不出现。

本次交付：买齐本级需要的开车装置后，车道打开、门洞不封、`DriveThruLane` 启用，车辆沿**南侧马路**排队、点餐、打包、离开；交一单仍记 `ShopGoalKind.CarOrder`。写明生成条件，补上试玩漏洞。

本次不做：改售价、新车型、072 柜台/烤台、069 桌数、071 堂食 Walk、恢复 Lv.13 存档、Android、全局调价。

## 玩家价值与成长衔接

- 玩家当前：会打包蓝盒（Rank 5），点 Upgrade 进入 Rank 6。证据是任务停在开车单、现场无车。不是新玩法，是既有得来速在等级表改位后断环。
- 现实：开车窗口开张才会来车。本作简化为「买开车柜台/车道 → 车沿南街排队」。
- 解锁：Rank 5 只给厢房和打包；Rank 6 才卖车道并要完成开车单。前置（打包台）在 Rank 5 已可达。
- 对经济：不改 150/250 与每件 15。修好后 Rank 6 不再死等（I2）。

## 经济与节奏依据

- 装箱 150、车道 250、开车每件 15，均沿用 022，不改。
- 不改 `StarCap(6)=14`、CycleCost、烤台/柜台参数。
- T(n) 不因本次改变；只消除「任务要求开车但系统不生成车」。

## 玩家流程与规则

| 项目 | 明确规则 |
| --- | --- |
| 生成条件 | Rank ≥ 6 且开车窗口/汽车厢已在世界上即刷车，见 **074**。买 `LANE` / 超市 Drive-thru 仍可开车道，但不是必做项。不要求包装柜已有蓝盒才会刷车；没货时车在窗口等。 |
| 购买必须开车道 | 若玩家仍走购买：买下开车装置后南门保持打开、创建或启用 `DriveThruLane`、绑定已有装箱台、开始生成。Rank 6 窗口已开时由 074 自动完成同一件事。 |
| 两件商品 | 装箱（BOX / Blue-box packing，Rank 5）与开车柜台（LANE / Drive-thru counter，Rank 6）仍是两笔。Rank 6 只买开车柜台必须足够刷车。若实现上还需要装箱台，超市必须在 Rank 6 仍卖得出装箱台，**不得暗中要求 Rank 7**。第一台开车柜台价格仍是 **250**，不得因为装箱台的包装柜被误登记成已拥有 `CarCounter` 而涨到 320。 |
| 车辆动线 | 车走南侧马路路点（spawn → 窗口队列 → 离场），用车道自身坐标，**不**走堂食 `ShopLayout.Walk`。最多 3 辆、停窗口、无货不离，规则同 022。 |
| Rank 5 未买车道 | 汽车厢可按 064 打开，**不刷车**。 |
| 成交 | 窗口交一单仍 `RecordMilestone(CarOrder)`，070 补满星星并出现 Upgrade。 |
| 费用 | 不改 |

试玩漏洞（本文件要堵上）：

1. `FacilityLayout` 把装箱台的 `CounterRoot` 提前 Wrap 成 `car-counter`，超市以为已拥有开车柜台，第一台标价变成重复购买价，世界 `LANE` 垫块被 `SetStoreOnly` 藏掉。
2. 超市放置开车柜台时 `RoadFits` 用的南街地块过窄（车宽 3.4 超出 `z∈[-32,-27.5]`），红影无法落成，购买完不成，车道从不 `Create`。
3. 自定义设施 `Activate` 不把子物体上的 `DriveThruLane` 登记到 `ShopExpansion` / 员工，存档 `boughtDriveThru` 可能仍为 false。
4. 只买装箱后，包装柜 `PackageDesk` 仍在窗口位但不是 `FacilityInstance`；超市 `CanPlace` 把它当固定墙（`Overlaps a fixed wall`），Rank 6 买车道仍然落不成。世界 `LANE` 垫块不走 `CanPlace`，所以垫块路径能开、超市路径不能。

## 边界、存档与兼容

不新增存档字段。旧档 `boughtDriveThru` 为真则进入后按 Rank 开门并刷车。仅有装箱、未买车道但 Rank 6 厢房已开：按 **074** 刷车，不再要求再买车道。包装柜库存与路上的车仍不存。

| 情况 | 预期行为 |
| --- | --- |
| Rank 5 未买车道 | 不刷车 |
| 已买车道但包装柜空 | 车照来，停在窗口等 |
| 只买装箱、未买车道 | Rank 6 厢房/窗口已开则刷车（074）。超市额外开车柜台仍可买 |
| 超市购买 / 世界垫块 | 任一完成都创建并打开车道 |
| 切后台 | 车上的车不存；重开后再刷 |
