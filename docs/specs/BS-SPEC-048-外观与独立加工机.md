# BS-SPEC-048 外观与独立加工机

用户要求：改进汽车模型，汽车交易改为临街窗口，修齐蓝色人行道连接处，外卖产线使用房间内独立加工机。

- 汽车增加可见轮胎轮毂、车顶、分隔车窗、后视镜、车灯、保险杠。保留排队、数量、速度及订单价格。
- 原汽车工作区保留存档设施位置，补外墙及小取餐窗口、窗台、雨棚，员工仍在内部操作。
- 移除入口重复铺设的高层蓝色地板；街区横向步道与纵向步道外缘对齐。保留防坠落碰撞。
- 自动外卖线解锁时生成独立加工机，位于外卖房间 (3,20)，仅供应传送带；堂食机器不再扣库存，也不再牵动链条。生产按基础汉堡机 3 秒/件，缓存使用产线容量 8。新设备属于整条自动产线，不另加购买/升级价格。本次新增产能是用户要求分离供货的结果，价格和升级数值不变。
- 不新增存档字段，已有设备布局及货币保留，加工中的库存继续不持久化。

验收：汽车与窗口实际渲染、步道接缝、防坠落；独立加工机位于外卖房间且不消耗堂食库存，自动流程正常；既有汽车与外卖测试回归。
