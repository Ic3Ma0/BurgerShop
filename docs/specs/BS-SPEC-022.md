## 目标与范围

玩家目前是：烤台出散装汉堡 → 绿圈取餐 → 柜台放餐 → 白圈堂食出餐（纸币 10）→ 入座/垃圾。南侧有强化房门，东侧有 HR。没有装箱，也没有外送窗和车道。

本次之后：花钱解锁装箱台后，玩家/员工可把散装汉堡打成包装盒并码到包装柜台。再花钱解锁得来速后，窗口有车等候且包装柜有货、人站在窗口绿圈，即可把套餐交给车辆；窗口旁掉绿色纸币 **15**，玩家走过才入账。堂食仍可直接拿散装汉堡。两线抢同一炉库存。

本次交付：

- 装箱台解锁 **150**：买完出现装箱桌、装箱绿圈、成品包装柜台。
- 得来速窗口+车道解锁 **250**：买完出现窗口、马路、车辆队列（最多 2–3 辆）。
- 开局没有装箱/车道。没买窗口时不能外送卖钱。
- 烤台汉堡必须先装箱才能外送；堂食散装循环（柜台 / 桌子 / 纸币 10 / 垃圾）不动。
- 员工可以装箱、把盒子放到包装柜、去窗口卖给车上的顾客。员工不吸钱。
- 外送成交价 **15**，复用 `CashPickup`，走过才入账。
- 任务胶囊：`Box the burger` / `Stock the package counter` / `Sell a combo`。
- 存档升到 version **6**：是否已买装箱台、是否已买得来速。包装柜库存不存（会话）。旧档视为未买。

本次不做：

- 不回滚强化弹窗、员工升级、纸币放大、019 额外桌/机/柜。
- 不引入 Pizza Ready / Kingshot / Doughnut 名称、立绘、车模或截图。
- 不做真实交通物理。
- 不 commit / push。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` 组装。装箱台与车道放在店南 / 外侧空地（图 4 马路在店前），不堵 HR 东门与南侧 Boost 门。

| 项目 | 明确规则 |
| --- | --- |
| 装箱解锁 | 玩家站在装箱购买圈约 **1.5s** 且余额 ≥ **150** → 扣款；出现装箱桌、绿圈、包装柜台。圈消失。 |
| 得来速解锁 | 玩家站在车道购买圈约 **1.5s** 且余额 ≥ **250** → 扣款；出现窗口、马路、车辆队列。圈消失。没买窗口不能外送卖钱。 |
| 装箱 | 手上有散装、装箱台已解锁、站在装箱绿圈 → 散装 −1、包装盒 +1。共享携带上限。 |
| 上柜 | 手上有盒子、站在包装柜台旁 → 盒子放到包装柜。逻辑无上限（可见码放至少 8）。上柜后仍可从该库存出货。 |
| 外送 | 窗口已解锁、有车在窗口停住、包装柜有货、人站在窗口绿圈 → 柜 −1（不必手持盒子）；盒子从窗口飞向车窗 0.42s，车保持停下；飞完后窗口旁掉 **15** 纸币，车才离开；`CompletedSales` +1（开始交货时）；`Coins` 不变直到玩家捡起。 |
| 堂食 | 散装仍可放堂食柜台、白圈出餐、入座、桌边纸币 10、垃圾。不要求装箱。 |
| 库存 | 装箱与堂食抢同一炉（及 019 额外烤台）散装库存。 |
| 员工 | 在出餐 / 清桌 / 取餐之外：有散装且装箱已解锁 → 去装箱；手上有盒子 → 上包装柜；包装柜有货且窗口有停好的车 → 去窗口卖。不捡地上纸币。 |
| 车辆 | 最多同时 **3** 辆。沿马路路点移动，到窗口位停下（速度 0）等候交货。无货不得驶离窗口。交货动画播完后沿路离开并销毁。无物理车体。 |

三个台面（英文标签 `BOX` / `PACK` / `WINDOW`，不要写 15，避免和地上纸币叠成 1515）：

| 台 | 标签 | 作用 |
| --- | --- | --- |
| 装箱桌 | `BOX` | 拿散装汉堡站绿圈 → 变成盒子（手持） |
| 包装柜台（高柜 + 纸盒塔） | `PACK` | 放下/存放包装盒库存，供窗口出货 |
| 得来速窗口（靠马路矮柜） | `WINDOW` | 站绿圈，把包装柜台的一份交给**停住的车** |

外送成交不要求手里再拿着盒子。柜上有货 + 窗口有停好的车 + 人在绿圈内即可：优先从包装柜库存 −1。没有停好的车或包装柜空则不能卖；车必须停在窗口位（速度 0），不得无货通过。

交货动画：一份盒子从窗口飞向车窗 **0.42s**（允许 0.35–0.5s），飞完后窗口旁掉 **15** 纸币，车才离开。

建议循环：烤台取散装 → 装箱绿圈打成盒 → 放到南侧包装柜 → 窗口绿圈交给等候的车 → 捡 15 纸币。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 未买装箱台 | 不能装箱；手上只有散装；包装柜不存在 |
| 未买窗口 | 即使有盒子也不能外送卖钱 |
| 包装柜空 / 窗口无车 | 站在窗口绿圈不成交 |
| 堂食 | 散装仍可上柜、出餐、掉 10 纸币 |
| 员工与玩家同时装箱或卖 | 共享包装柜与窗口冷却；员工不捡钱 |
| 切后台 | 包装柜库存与路上的车不存；重开后车道空、柜空，已购设施仍在 |
| 旧存档 version ≤ 5 | 装箱台与得来速视为未买；金币、烤台、雇佣、019 / 020 / 021 字段保留 |

存档新字段从 version **6** 起：`boughtBoxingStation`、`boughtDriveThru`。不得改写 v3 / v4 / v5 checksum。包装柜库存、车上是否在等、手上盒子不写存档。

允许开发自行决定的可逆细节：车身配色、路宽、码放层高（不得改价格、15 成交、坐标与「先装箱才能外送」）。
