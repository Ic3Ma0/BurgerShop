# BS-SPEC-057 流水收钱反馈交付

对应 v1.0；已完成本地实现，未推送 GitHub。

## 实现

- CashFloor 按同一落点的余额拆包/合包，每 0.07 秒发出一包，0.30 秒飞到胸前才入账。小额保持快速；大额初始最多约 32 包，零头精确保留。200 笔各 10 与单笔 1000 都在测试的 2.5 秒窗口内完成。
- 修复实际加速原因：多个 BurgerServingZone 原来每帧各推进一次共享 CashFloor，柜台越多收取越快。现在运行时只有 CashFloor 自己推进一次；显式 Advance 的隔离模拟仍保持原接口。
- 大额单堆按剩余金额缩小，多笔高堆保持压缩比例并逐层减高。薄纸币束先抬离钱堆轮廓，再向镜头侧划弧飞到胸前，避免被高堆遮住；不再整座高堆一起消失。走开停止新发包，在途追随玩家；暂停不推进。
- CoinSfx 使用本地生成的纸币轻响与清脆入账声；FeedbackDirector 允许正常流水节拍，音高从 1 小幅上扬至 1.30 后封顶，停顿 0.35 秒重置。同帧重复请求拒绝，保留 4 音轨预算和 Sound 开关。HUD 每批发出一个绿色纸币反馈，数量累计。
- 新节奏参数集中于 CashCollectionFeel。收入金额、收入加成、订单数、价格、升级曲线及存档 schema 不变。拆包不重复应用收益加成；钱包接近上限时预留在途金额，途中无法入账则原额退回。
