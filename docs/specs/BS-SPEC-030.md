# BS-SPEC-030：堂食桌椅升级与套装选择

- 版本：v1.1
- 状态：可开发 / 开发中
- 对应基线：本地 `feat/shop-rank` 含 026–028 UI 打磨；本仓库无 BS-SPEC-029。商店等级不在本刀范围。
- 优先级与原因：用户要求已建成的吃饭桌椅可升级；升级完成弹出选类型框；不同类型有不同属性；堂食吃完后落地金币变多。
- 前置依赖：023 设施分次投入、016 落地现金、013 入座用餐、026 弹窗视觉。不依赖未出现的 029。
- 用户已确认：要做桌椅升级、完成时选类型、用餐产生更多钱。下列数值是 BurgerShop 产品建议，**不是**对参考截图或 Pizza Ready 的测量。
- 产品建议或关键未定项：参考图只说明意图（横幅 TABLE CHANGE / Level 2、三张家具卡）。本刀不抄钻石、广告、券、第二货币或截图像素。

## 目标与范围

玩家目前：开局三张红桌蓝椅，用餐结束每桌落地 **10** 金币；另有绿色投入圈可花 150 建第四张桌。桌椅外观与堂食金额都固定。

本次之后：已建成的每张桌旁有紫色升级圈。站在圈内按现有分次投入扣金币；**该桌 80 金币投满**即「升级完成」，弹出英文选套框。三套家具属性不同，**每一套的堂食落地金币都高于 10**。选定后桌椅换占位配色，用餐时长可加快；重开仍保留套装与加成。

本次交付：

- 仅已建成的开局三桌，以及已买下的加桌（含 [031](BS-SPEC-031.md) 四人桌与方桌），可升级。未建成的桌没有升级圈。
- 每桌一次升级：Level 1（开局套）→ 投入完成并选套 → Level 2。本刀无 Level 3。
- 投入完成弹出 `TABLE CHANGE` / `Level 2`，三张卡用金币已付清的 `SELECT` 选定套装。
- 堂食结束落地金币按该桌当前套装结算；柜台与得来速金额不变。
- 存档升到 version **8**，写入每桌套装与投入。

本次不做：

- 钻石、广告、券、第二货币、看广告免费、HOT 付费标签。
- 升级完成额外奖金币或店铺等级奖励。
- 员工成长、得来速专用堂食加成、新 3D 家具包、离线收益。
- 全屏锁死摇杆；新的 3D 交互流程。
- 商店等级（若 029 未在本检出）或员工桌椅升级。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装。升级圈在每张已建成餐桌东侧；选套框挂在 `JoystickCanvas/SafeArea`。

| 项目 | 明确规则 |
| --- | --- |
| 可升级对象 | `ShopLayout.Tables` 三张开局桌。第四张两人加桌仅在已购买（`boughtExtraTable` / 现场已生成）后出现升级圈。031 四人桌 / 方桌同样：买下才有紫圈。未建成的桌只保留对应绿色购买圈。 |
| 升级圈 | 紫色圆柱，半径 **1.0**，圆心 = 桌心 + `(1.55, 0.02, 0)`。颜色用途与烤台升级圈相同（紫=升级）。不改绿取餐 / 白收银 / 青雇佣。 |
| 触发投入 | 玩家站进该桌升级圈。进入等待 **0.3** 秒，之后每 **0.1** 秒投入最多 **10** 金币，与 023 相同。员工不投入。 |
| 费用 | 每桌 **80** 金币。取「10、钱包、剩余」最小值。离开立即停；已投入不退。钱包为 0 时暂停，仍站在圈内又获得金币则继续。 |
| 同时投入 | 与 023 共用「最近投入圈」：任意设施建造圈与桌椅升级圈不得同时扣款。 |
| 升级完成 | 该桌累计投入达到 80 的那一笔提交后：不再扣该桌的钱；播放既有短反馈 `Level Up!`（不发额外金币）；桌仍是开局套与 10 金币堂食，直到玩家选套。 |
| 弹窗 | 升级完成后立刻弹出。玩家可用右上角 Close 关掉；不退款、不选套。离开该圈再走进，未选套则再弹出。不比现有玩家/员工升级框更强地锁摇杆。 |
| 选套 | 三张卡均为 `SELECT`，选定不再扣钱。点一张立即应用该套并关掉弹窗、收起紫色圈。本刀不可改选。 |
| 未选套 | 投入已满且套装仍为开局：重开后该圈仍在，走进再弹出，不二次收费。 |
| 用餐结算 | 顾客在该桌吃完、离开座位的那一刻，按**当时**套装的 `MealPay` 落地。用餐过程中途完成选套，则该餐按新套装结算。 |
| 柜台 / 得来速 | 柜台落地仍 10；得来速既有规则不变。桌椅加成只作用于该桌 `LeaveMealCash`。 |
| 用餐时长 | 顾客每帧读取该桌 `EatSeconds`。开局 **3.0** 秒。 |
| 朝向 | 换套只改桌面/椅垫占位颜色，不重建椅。椅 `forward` 仍朝桌心，靠背在外侧。 |

### 套装（Level 2 三选一）

开局套不出现在弹窗里。三套都必须提高堂食落地金币。

| 套装 | 英文名 | 堂食落地 | 用餐时长 | 卡上英文 |
| --- | --- | --- | --- | --- |
| 开局 | Starter | 10 | 3.0 s | （无卡） |
| 小馆 | Bistro | 12（PAY +2） | 3.0 s（不变） | `PAY +2` / `—` |
| 餐车 | Diner | 12（PAY +2） | 2.4 s（SPEED +20%） | `PAY +2` / `SPEED +20%` |
| 露台 | Patio | 15（PAY +5） | 2.7 s（SPEED +10%） | `PAY +5` / `SPEED +10%` |

SPEED 百分比表示在开局 3.0 秒上缩短用餐时间：+20% → 2.4，+10% → 2.7。这些是 BurgerShop 整数金币与可测时长，不是参考图里的 +7% / +20% / 钻石价。

## 界面与资源

- 入口：桌旁紫圈。投入中世界文案 `TABLE` + `Remaining N`。待选套时 `PICK SET`。选完后圈与文案消失。
- 弹窗英文：标题 `TABLE CHANGE`，副标题 `Level 2`。三张奶油色卡：套装名、属性、绿色 `SELECT`。右上角 Close。无钻石图标、无 `FREE`、无广告按钮、无 `HOT` 付费角标。
- 界面语言：英文。沿用 `HudChrome` 奶油卡 / 番茄红强调 / 安全区。弹窗居中偏上，不得挡住左下摇杆保特区。
- 参考图：[table-change-reference.jpg](../images/spec030/table-change-reference.jpg) 只作意图，不进口游戏、不要求像素级复刻。
- 资源：运行时 primitive + `RuntimeMaterials`。Bistro 橙桌黄椅、Diner 青桌米椅、Patio 蓝桌红椅。禁止 Pizza Ready 素材与商标。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 钱不够 | 投入停在剩余金额；圈仍在；不弹选套。 |
| 未建成加桌 | 无第四个紫圈；不能升级不存在的桌。 |
| 已满级（已选套） | 无紫圈，不再扣钱。 |
| Close / 离开 | 不退 80，不选套；再进圈再弹。 |
| 多桌待选 | 只为玩家当前所在、且最近的待选桌弹窗。 |
| 切后台 | 不继续投入；恢复后重新 0.3 秒进入等待。 |
| 旧存档 v1–v7 | 三桌与加桌（若已买）均为开局套、投入 0；金币/设施/员工/升级保留。未买加桌的加桌字段必须当作 0。 |
| 新存档 | version **8**。每桌 `tableNSet` 0–3，`tableNInvestment` 0–80；加桌另有 `extraTableSet` / `extraTableInvestment`。套装非 0 时该桌投入必须为 80。未买加桌时加桌套装与投入必须为 0。投入=80 且套装=0 表示待选。 |
| 合法满额未选套 | 读档后补齐待选状态，不扣第二次钱。 |

不持久化弹窗开关、Close 状态或玩家位置。允许开发自定：紫圈厚度、卡内色块曲线、短反馈粒子；不得改 80 / 套装金额 / 时长 / 圈半径与偏移。

## 验收标准

| 编号 | 初始状态 | 操作 | 必须出现的结果 |
| --- | --- | --- | --- |
| AC-01 | 新开局，钱包 80，三张开局桌 | 站进第一张桌紫圈至投入结束 | 钱包 0，弹出 `TABLE CHANGE` / `Level 2` 三张英文卡；未选套前该桌用餐仍落地 10。 |
| AC-02 | 承接 AC-01 弹窗 | 点 Patio 的 SELECT | 桌椅换 Patio 占位色；椅仍朝桌心且靠背在外；紫圈消失；该桌再吃完落地 15。柜台仍 10。 |
| AC-03 | 新开局，点 Diner | 顾客入座用餐 | `EatSeconds` 为 2.4；落地 12。Bistro 仍 3.0 秒、落地 12。 |
| AC-04 | 钱包 40 | 站进紫圈直到停止 | 投入 40、剩余 40、无弹窗；离开再进只补 40。 |
| AC-05 | 加桌未买 | 走到加桌建造圈附近 | 只有绿色 TABLE 建造圈，没有第四个紫圈。买下加桌后才出现紫圈，该桌独立 80。 |
| AC-06 | 投入满、未选套 | Close，离开，保存并重开，再走进 | 不扣第二次 80；再弹出选套；金币与待选状态同时恢复。 |
| AC-07 | v7 旧档已有金币与已购加桌 | 加载 | 桌椅开局套；旧金币/设施保留；下次写入 version 8。非法套装或未买加桌却有加桌投入的档案拒绝写入。 |
