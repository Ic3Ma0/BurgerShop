# BS-SPEC-027：移动、镜头与交互手感打磨

- 版本：v1.2；2026-09-12；状态：0.2.1 本地实现与主要技术验证完成；未完成验收项见交付记录，未合并。
- 基线：本地 0.2.0；优先级 P1；依赖现有摇杆/角色/镜头，与 026 协调操作区域。
- 用户已确认：打磨手感；本版阈值与时长为产品建议，不是对参考游戏的测量。

## 目标与范围

让小幅移动更可控、停止可靠、转向自然，镜头不干扰玩家对准交互点。保留角色实际速度升级、地图、碰撞、搬运容量及所有经济/服务时长。

源码基线：VirtualJoystick 有 0.08 死区，PlayerMotor 又过滤 0.12；CameraFollow 同时平滑位置和朝向。当前属于源码观察，尚未用本轮实机对照证明延迟或眩晕。

## 操作与镜头规则

1. 保留左下固定摇杆，本轮不改全屏浮动摇杆。单一径向死区 0.10；有效输出在死区外按 `(幅度-0.10)/0.90` 连续映射到 0–1，角色层不再次截掉低幅输入。
2. 保留模拟力度调速、斜向速度不超直线、摄像机相对移动。满杆最大速度及所有已购加成不变。
3. 从静止收到有效输入，在下一个正常游戏 Update 开始移动；松手、触摸取消、失焦或后台后下一个有效 Update 清零移动。此次不增加惯性滑行或停止缓动，不能为了柔顺而越过购买区边缘继续扣钱。
4. 角色外观朝移动方向平滑转向，目标是满幅 90° 转向在 0.10–0.18 秒内进入目标 ±5°；反向不经过长时间绕圈。碰撞方向和移动输入立即响应，不等待模型转完。转向只调视觉，不降低实际移动速度。
5. 镜头保持现有斜俯视角度和取景尺度。跟随平移时固定相机旋转，不因追逐角色瞬时偏移持续改变操作坐标。位置平滑目标：角色停止后 0.25 秒内收敛到目标距离的 95%；首次进入和重新设置目标时直接定位。
6. 收钱、成交和普通加工不震屏、不强制缩放。升级反馈也不接管镜头，保留玩家可操作性。
7. 交互区用安静边界表示可操作位置；实际触发时边界增强并显示当前动词，如 `Collect`、`Serve`、`Packing`。视觉必须由真实是否满足条件驱动；满载、缺货时不能表现为正在加工。
8. 不扩大实际拾取/投入/服务范围，也不通过“离开宽限期”改变 023 停止支付规则。相邻区仍可独立进入。
9. 摇杆第一个有效指针独占控制，第二根手指不得抢走；主指松开后输出归零，不自动继承仍按着的第二指。点击升级按钮不造成角色跳转或摇杆位移。

## 边界与兼容

不新增经营持久化数据；键盘 WASD 保留，归一化后速度与满杆一致。应用后台不累计移动/镜头动画时间，恢复时摇杆归零。镜头改变后须实测房间门口、打包区、南侧车道可见性，不靠任意放大 FOV 掩盖问题。

## 验收标准

- AC-01：输入幅度 0、0.09、0.10、0.11、0.5、1，验证死区内为零、外部连续单调、最大速度与旧版一致；同样时长斜行距离不超过直行。
- AC-02：触摸松开、移出摇杆边界后松开、主副指互换、后台恢复各重复 10 次，无持续移动或误触购买；下一 Update 的输入及速度归零有日志佐证。
- AC-03：实际沿墙、穿门、绕烤炉、准确进入 BOX/PACK/窗口，再停止分次投入，均能操作；单独记录误入相邻区域和碰撞卡住情况。
- AC-04：满杆直行、90° 转向、反向、停止的录像与输入/旋转轨迹满足时长目标；镜头转角保持恒定，停止后的跟随收敛符合目标。
- AC-05：旧存档最高速度/携带升级仍有效；视觉转向与镜头修改不改变服务、产出、投入间隔。
- 本地验收：同一 Unity 环境、同一存档和路径各录一段改前/改后 60 秒 Play 操作，含小幅挪动、连续转弯、急停；多指点按钮另用输入模拟/测试验证。报告主观改善及仍有的问题，标注为本地结果。
