# BS-SPEC-019：花钱解锁新桌子、新汉堡机、新柜台

- 版本：v1.1
- 状态：已实现（开局机同步外观；库存随等级；EditMode 已过，未做真机）
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-013](BS-SPEC-013.md)～[BS-SPEC-018](BS-SPEC-018.md) 之上
- 优先级与原因：用户手头约 600 金币，批准用中规中矩价格加三件**额外**设施；新汉堡机要逐级大改外观，不能只改秒数。
- 前置依赖：013 柜台/桌子；015 1.5× 场地与三档雇佣；016 纸币；017 HR；018 升级震动/`LVn`/金币音。
- 用户已确认：本刀已批准；价格约 **150 / 200 / 250**；升级不要用 10。
- 产品建议或关键未定项：占位几何 + `RuntimeMaterials`。禁止 Pizza Ready 贴图、名称、截图或商标。

## 目标与范围

玩家目前是：开局已有 3 桌、1 烤台、1 柜台；紫色圈只把**现有**烤台按 30 / 60 升到 LV2 / LV3，外观只加灯和炉面。

本次之后：空地上有三个绿色钱堆圈。站上去约 1.5s 且钱够则解锁一件额外设施。新汉堡机以 LV1 出现（约 3s/份），再在该机旁升级圈按 80 / 160 升到 LV2 / LV3；**每次升级必须效率明显加快，并且体量、颜色、烟囱/灯/炉面层数至少两项巨变**，升级瞬间沿用 018 的震动与弹出 `LVn`。新柜台加入放餐/出餐；新桌子加入用餐区。

希望解决：600 金币花不出去、店面不能变大、升级看不出换了一台机器。

本次交付：

- 三个绿色钱堆/地面圈（占位几何）：新桌子 **150**、新汉堡机 **200**、新柜台 **250**。买完圈消失或变成已购买。
- 开局仍保留现有 3 桌 + 1 烤台 + 1 柜台，游戏能玩。这三个是额外设施。
- 新汉堡机 LV1 出餐约 3s/份；旁有紫色升级圈：LV2 **80**、LV3 **160**。不要用 10 当升级价。
- 新柜台可放可卖（白圈），与原柜台共享顾客队列和收银冷却。
- 新桌子 2 椅、朝桌心、会脏、掉纸币。
- 存档记录是否已买桌/机/柜、新机等级（字段从 version **3** 起）。当前写入 `RestaurantSaveData.CurrentVersion`（现为 **4**，并行刀另有员工档位）。旧档默认都没买，金币与既有进度保留。
- 任务胶囊可提示 `Install a table` / `Install a grill` / `Install a counter`。

本次不做：

- 不回滚 HR、1.5×、员工特色、纸币捡钱、纸团、柜台无上限、升级跳动/金币音。
- 不改现有烤台升级价 30 / 60、雇佣 50 / 100 / 200、成交价 10、手持 4、开局 3 桌。开局烤台升 30/60 时换同一套 `Look_Lv2/3` 外观，库存随等级涨。
- 不引入 Pizza Ready 素材；不从网上下载版权贴图。
- 不 commit / push。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` 组装。三个购买圈放在空地，不堵入口、HR 门洞和现有桌子。

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 玩家站在对应绿色圈内停留约 **1.5s**，且余额 ≥ 价格 → 扣款并解锁。同一次停留只买 1 件。钱不够不扣、不解锁。 |
| 费用 | 新桌子 **150**；新汉堡机 **200**；新柜台 **250**。新汉堡机升级：LV1→2 **80**，LV2→3 **160**。现有烤台仍 30 / 60。 |
| 状态变化 | 买完：圈消失或标成已购买；对应家具出现并可交互。新汉堡机出现时为 LV1、约 3s/份。该机升级每次只升 1 级，效率加快且外观换套。满级静态 `MAX`，再停留不扣钱。 |
| 新桌子 | 加入 `DiningArea`：2 椅、`LookRotation` 朝桌心、靠背在外侧；用餐后脏、掉纸币，规则同 013 / 014 / 016。 |
| 新汉堡机 | **独立库存**（LV1=**4**、LV2=**6**、LV3=**8**）与绿色取餐圈。玩家/员工从有货的机子取餐。升级圈在机旁，紫色。满了才停产。 |
| 新柜台 | 独立柜台库存（无上限）+ 白圈。玩家/员工可在此放餐、出餐。与原柜台**共享队列与收银冷却**，额外搬运者不能靠第二白圈跳过 `servingInterval`。出餐仍掉纸币、不直接加金币。 |
| 与已有功能的关系 | 共享钱包。现有烤台/柜台/3 桌开局可用。员工仍送汉堡、清桌、不捡钱。 |

建议循环：先按日常出餐赚钱；走进绿色钱堆圈买桌子或机器；新机旁再花 80 / 160 看外观和出餐变快。

## 界面与资源

- 购买圈：绿色地面圆 + 占位金币堆几何，英文短标（`TABLE 150` / `GRILL 200` / `COUNTER 250`）。已购买则圈消失或 `OWNED`。
- 新汉堡机三档外观必须可测：每级子物体数量、名字、根 `scale` 都不同。至少两项巨变：体量、主体颜色、烟囱数量、灯数、炉面层数。
- LV2 / LV3 升级瞬间：工位短震动+放大、弹出 `LV2` / `LV3`；满级留 `MAX`。读档只显示当前套，不播动画。
- 任务胶囊可出现 `Install a table` / `Install a grill` / `Install a counter`（汉堡英文，不要 pizza）。
- 圈颜色：绿取餐 / 绿钱堆购买 / 白收银 / 紫升级 / HR 雇佣。不挡左下摇杆。
- 资源：运行时 primitive + `RuntimeMaterials`。禁止 Pizza Ready 贴图。

## 新汉堡机外观与产能

| 等级 | 开局机产能（仍 30/60） | 新机产能（80/160） | 库存上限 | 外观（至少两项相对上一级巨变） |
| --- | --- | --- | --- | --- |
| LV1 | **3.0s**/份 | **3.0s**/份 | **4** | 小钢柜、单层黑炉面、无烟囱、1 盏小灯；根 scale **1**；套件名 `Look_Lv1` |
| LV2 | **2.0s**/份 | **1.5s**/份 | **6** | 体量明显放大（根 scale **1.22**）、铜橙机身、**双层**炉面、**1 根**高烟囱、2 灯；套件名 `Look_Lv2` |
| LV3 | **1.5s**/份 | **0.8s**/份 | **8** | 再放大（根 scale **1.45**）、铬红机身、**三层**炉面、**双烟囱**、顶灯/信标；套件名 `Look_Lv3` |

开局烤台与新汉堡机用**同一套** `Look_Lv*`（scale、炉层、烟囱、灯）。出餐托盘/汉堡堆跟当前套件的 `OutputTray`，世界坐标在炉面上方，不被机身或世界字盖住。每台机只留一行世界字：`GRILL n/max`，满级再写 `MAX`，不要重复 `FULL`。升级价：开局机仍 30/60，新机仍 80/160。
