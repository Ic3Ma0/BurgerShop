# BS-SPEC-014：用餐留垃圾与垃圾桶

- 版本：v1.1
- 状态：开发中
- 对应基线：已验收 MVP **0.1.2**，并叠在 [BS-SPEC-013](BS-SPEC-013.md) 柜台出餐 / 入座用餐 / 任务胶囊之上（工作区可能已有最多 3 张桌）
- 优先级与原因：用户已批准「吃完留垃圾、玩家自己清到垃圾桶」，用来补上用餐后的桌面循环，且不要雇员工代劳。
- 前置依赖：[BS-SPEC-013](BS-SPEC-013.md) 的桌子、3 秒用餐、白圈出餐、任务胶囊。
- 用户已确认：本刀已口头批准，不再二次确认。实现用每人正好 2 个垃圾，不随机、不改经济。
- 产品建议或关键未定项：垃圾桶用占位几何即可。任务文案用英文短句。多桌时每张桌独立脏净。

## 目标与范围

玩家目前是：顾客在桌子上吃约 3 秒后离场，座位立刻空出，下一位可以直接再坐。

本次之后：每位顾客吃完在该桌留下正好 2 个大纸团；**只要桌上还有垃圾，整桌都不能坐**，后来的人在该桌 `WaitPosition` 旁观面向桌子，或去完全干净的别的桌子。玩家把桌上纸团捡走（清空）后才可再坐。玩家再把纸团投进垃圾桶。不得走到绿块消失。

希望解决：用餐没有善后、座位可以无限复用、玩家缺少「清桌」这一步；纸团太小看不清；拾取/投放瞬间消失。

本次交付：

- 用餐结束在该座位留下正好 2 个可见大纸团（白/浅灰皱纸，几个错开旋转的球体叠成一团，体积约一个汉堡或更大），掉在桌面上。
- 新增一个垃圾桶占位道具（深灰桶+盖），放在用餐区附近。
- 玩家靠近脏桌自动拾取：纸团 hop 后飞向玩家（约 0.35 秒），再进无限垃圾背包。靠近垃圾桶自动投放：纸团飞向桶口，略弹后落入缩小消失（约 0.35 秒）。不要瞬间删。
- 玩家垃圾携带数量无限，不占用汉堡 4 个上限。
- 一张桌只要还有可见垃圾（含正在飞向玩家的纸团），`TryAssignSeat` / `DiningArea` 不得分配该桌任何座位。
- 任务胶囊在脏桌/手持垃圾时提示清桌或去垃圾桶；不挡左下摇杆。
- 垃圾是会话状态：关游戏不存。

本次不做：

- 不改单价 10、烤台升级 30/60、出餐间隔、汉堡手持上限 4、烤台库存 4、用餐 3 秒。柜台无上限见 013 v1.3。
- 本刀只做玩家清桌。员工清桌、三档雇佣与扩店见 [BS-SPEC-015](BS-SPEC-015.md)。
- 不引入 Pizza Ready 名称、截图、模型或商标文案。
- 不改摇杆位置、尺寸、触控。
- 不回滚 3 张桌、椅子朝桌心、垃圾桶、HUD、无限垃圾背包。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装店铺。桌子与垃圾桶开局即存在。

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 顾客在座位上吃完 → 该桌留下正好 2 个大纸团，顾客离场。玩家进入脏桌拾取半径且桌上仍有垃圾 → 每次间隔至多拾 1 个，纸团先 hop 再飞向玩家。玩家进入垃圾桶半径且手持垃圾 ≥ 1 → 每次间隔至多投下 1 个，纸团飞向桶口再落入。 |
| 费用 / 奖励 / 时长 / 上限 | 无金币增减。每人正好 **2** 个纸团，不随机。玩家垃圾携带 **无限**。拾取/投放间隔约 **0.25** 秒，每次 1 个。飞行动画 **0.35** 秒（0.25–0.45 可测）。汉堡循环与 3 秒吃饭不变。 |
| 状态变化 | 吃完：该座位 `outstanding` +2，桌上出现 2 个纸团，**整桌不可坐**。拾取动画播完：桌上 −1，玩家手持 +1；该桌可见垃圾清零后整桌可再坐（不必等投入垃圾桶）。投入动画播完：手持 −1，对应座位 `outstanding` −1。 |
| 与已有功能的关系 | 不占用汉堡库存/柜台/钱包。员工只跑汉堡柜台循环，不拾垃圾。绿取餐 / 白收银 / 紫升级 / 青雇佣圈位置与颜色不变。多张桌时各自独立脏净；只去**完全干净**的桌子。脏桌后来的人走到该桌 `WaitPosition` 附近面向桌子旁观，不要走出口绿块消失。 |

建议循环（写死）：

1. 烤台 → 绿区取餐 → 柜台放餐 → 白圈出餐（+10）不变。
2. 顾客入座吃约 3 秒，桌上留下 2 个大纸团后离场；该桌整桌不可坐。
3. 后来的顾客走到该桌旁边面向桌子等着，或去干净的别的桌子吃饭。
4. 玩家走近该桌，纸团飞向玩家后进背包（可连续捡多份，可超过 4）。桌上清空后旁观者可坐下。
5. 走到垃圾桶，纸团飞向桶口后消失。若还有其他脏桌，任务继续提示清桌。

## 界面与资源（涉及呈现时填写）

- 入口、显示位置、反馈时机：垃圾桶在用餐区附近地面；大纸团在桌面上，一眼能看见。拾取时纸团跳起再飞到玩家头顶附近；投放时从身上飞向桶口再缩小落入。任务胶囊仍在上方中央。携带 HUD 可额外显示 `TRASH n`（无上限分母），汉堡行仍为 `n/4`。
- 正常 / 不可用 / 进行中 / 完成状态及文案（界面语言：英文）：

| 当场状态 | 任务文案 | 进度 |
| --- | --- | --- |
| 手持垃圾 ≥ 1 | `Take trash to the bin` | 0/1，投完且桌上已无垃圾后回到经营目标 |
| 桌上有可见垃圾、手上没有 | `Clear the table` | 0/1 |
| 无脏桌且无手持垃圾 | 沿用 013 汉堡循环文案 | 不变 |

- 参考图或布局说明：垃圾桶不得挡住柜台白圈、烤台取餐绿圈、升级紫圈、雇佣青圈。摇杆仍为锚点 `(0,0)`、位置 `(220, 240)`、尺寸 `280×280`；新文案不得进入该矩形及其外侧约 24px 边距。`raycastTarget` 除摇杆外必须为 false。
- 资源交付：运行时 primitive + `RuntimeMaterials`。禁止 Pizza Ready 素材。纸团用白/浅灰球体叠成皱团，约汉堡大小或更大。垃圾桶建议深灰桶身 + 更深的盖。动画用现有物体 + `Advance(deltaTime)`，不依赖 Timeline/Animator 资源。

## 边界、存档与兼容（只写相关情况）

| 情况 | 预期行为 |
| --- | --- |
| 桌上无垃圾 / 不在拾取半径 | 不拾取 |
| 手持为空 / 不在垃圾桶半径 | 不投放 |
| 该桌仍有可见垃圾（任一座位） | 整桌任何座位都不可分配；已出餐顾客走到该桌 `WaitPosition` 面向桌子旁观 |
| 该桌垃圾已被捡走（桌上清空） | 空座位可再坐，即使纸团还在玩家手里未投桶 |
| 其他桌子仍完全干净 | 后来的顾客去干净桌子吃饭 |
| 全部桌子脏或占用 | 已出餐顾客在脏桌边等待；队列中的人继续排队，不要走到绿块消失 |
| 员工在场 | 014 只要求玩家能清；员工清桌由 [BS-SPEC-015](BS-SPEC-015.md) 追加 |
| 切后台与重新进入 | 沿用现有存档字段。桌上垃圾、手持垃圾、脏净状态重建为空 |
| 旧存档升级到本版本 | 不新增字段、不升版本。读 version 1 即可继续 |

不新增持久化状态。允许开发自行决定的可逆细节：垃圾桶精确世界坐标、拾取/投放半径（与现有 Zone 同量级）、纸团落点偏移、携带垃圾的堆叠视觉。飞行动画时长固定为 0.35 秒。

## 验收标准

| 编号 | 初始状态 | 操作 | 必须出现的结果 |
| --- | --- | --- | --- |
| AC-01 | 顾客已入座 | 吃完约 3 秒 | 该桌留下正好 2 个大纸团；顾客离场；整桌不可再坐 |
| AC-02 | 桌上有垃圾 | 玩家走进该桌拾取半径并停留 | 纸团飞向玩家后再进背包；桌上逐个减少直至清空；不消耗汉堡栏位 |
| AC-03 | 已拾起该桌的垃圾、尚未投放 | 走到垃圾桶放下 | 纸团飞向桶口再消失；手持减少；桌上已空则可坐 |
| AC-04 | 连续多名顾客用餐 | 观察数量 | 每人正好 2 个；玩家可同时持有超过 4 个垃圾 |
| AC-05 | 某桌仍有垃圾 | 下一位已出餐顾客找座 | 不会坐上该脏桌任一座位；有完全干净的桌子则去那里；否则在该桌 `WaitPosition` 面向桌子等，不从绿块消失；桌上被捡空后才可坐下 |
| AC-06 | 已雇员工 | 观察员工 | 014 范围：玩家仍可自己清。员工是否清桌以 [BS-SPEC-015](BS-SPEC-015.md) 为准 |
| AC-07 | 旧 0.1.2 存档 | 读取 | 金币、成交、烤台等级、雇佣、员工送单数保留；垃圾为空 |
| AC-08 | Editor `SampleScene` Play | 走完吃饭→捡垃圾→投桶 | 大纸团与垃圾桶可见；白/绿/紫/青圈仍可站；任务胶囊在脏桌时提示清桌 |
| AC-09 | 竖屏 HUD | 观察 | 胶囊与 `TRASH` 文案不挡左下摇杆 |
| AC-10 | EditMode 用 `Advance` | 播完 0.35s 飞行动画 | 数量在动画结束后才变化；脏桌整桌拒坐；旁观等待面向桌子 |

手机相关：建议在 vivo S50 竖屏确认靠近拾取/投放手感、垃圾桶不挡圈、胶囊不挡摇杆。本实现若无法装机，在开发报告标明未做真机。

不应破坏的既有行为：绿区取餐上限 4、烤台库存 4、升级 30/60、成交价 10、3 秒吃饭、白圈出餐、Android `RuntimeMaterials` + `link.xml`、3 张桌、椅子朝桌心。雇佣与存档见 [BS-SPEC-015](BS-SPEC-015.md)。
