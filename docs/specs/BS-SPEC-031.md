# BS-SPEC-031：可购买的四人桌与小方桌

- 版本：v1.0
- 状态：可开发 / 开发中
- 对应基线：`feat/shop-rank` 已含 [BS-SPEC-030](BS-SPEC-030.md) 堂食套装升级；本仓库无商店等级刀。
- 优先级与原因：用户要求从参考图增加两种**可购买**桌型：四人桌、带靠背椅的小方桌。放置触发仍是现有绿色钱堆投入圈。
- 前置依赖：019 加桌、023 设施分次投入、013 入座、030 桌椅套装。不依赖未出现的 029 / cola / PR #17。
- 用户已确认：要这两种桌；解锁方式是购买（与现有 TABLE 钱堆圈相同）。下列数值是 BurgerShop 产品建议，**不是** Pizza Ready 测量。
- 产品建议或关键未定项：本云环境未找到 `ref-four-seat-and-square-tables.png`。布局与观感对齐同批 TABLE CHANGE 截图里的**小方桌 + 有靠背椅 + 绿色钱堆圈**，以及一张长方形四人桌。不抄参考游戏名称、贴图、音频。

## 目标与范围

玩家目前：开局三张两人红桌；另有绿色 `TABLE` 圈花 150 建第四张**同款两人桌**。没有四人位，也没有外形不同的方桌。

本次之后：用餐区北侧再出现两个绿色钱堆圈。投满后分别放下**四人长桌**和**小方桌（椅背更高）**。顾客可入座；建成后走 030 的紫色升级圈与套装堂食加成。重开仍保留是否已买、投入与套装。

本次交付：

- 两个新购买圈，规则与现有 TABLE / GRILL 相同：进入等 **0.3** 秒，之后每 **0.1** 秒最多投入 **10** 金币。
- **四人桌 200**、**小方桌 150**。买完圈消失，家具出现在圈所在格。
- 四人桌 4 椅；方桌 2 椅且靠背明显高于开局椅。椅 `forward` 朝桌心，靠背在外侧。
- 建成后各有一枚 030 紫色升级圈（80 金币、同一套 Bistro / Diner / Patio）。未买则没有紫圈。
- 存档升到 version **9**。旧档默认没买这两种桌；金币、已购设施、030 套装保留。

本次不做：

- 钻石、广告、券、第二货币、可乐、商店等级。
- 替换开局三桌或取消现有 150 两人加桌。
- 新 3D 家具包、Pizza Ready 商标/音频、离线收益。
- 改 030 的 80 / 套装金额 / 用餐时长。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装。两圈从新开局就出现，不依赖是否已买第四张两人桌。

| 项目 | 明确规则 |
| --- | --- |
| 四人购买圈 | 绿色圆柱 + 金币堆，半径 **1.0**，文案 `4-SEAT` + `Remaining N`。圆心 = 四人桌位。 |
| 方桌购买圈 | 同上，文案 `SQUARE`。圆心 = 方桌位。 |
| 触发投入 | 玩家站进该圈。进入等待 **0.3** 秒，之后每 **0.1** 秒投入最多 **10** 金币，与 023 相同。员工不投入。 |
| 费用 | 四人桌 **200**；小方桌 **150**。取「10、钱包、剩余」最小值。离开立即停；已投入不退。 |
| 同时投入 | 与 023 / 030 共用「最近投入圈」，不得与其它建造圈或桌椅升级圈同时扣款。 |
| 建成 | 该圈累计达到标价的那一笔提交后：播放既有 `Built!`；圈与文案消失；对应桌加入 `DiningArea`。 |
| 四人桌 | 长方形桌面（南北向更长），长边东西侧各两椅，共 **4** 座。开局套堂食落地仍 **10** / 用餐 **3.0** 秒，直到 030 选套。 |
| 小方桌 | 桌面边长小于开局桌；南北两椅；靠背高度大于开局椅（可测）。座位数 **2**。开局套同样 10 / 3.0 秒。 |
| 朝向 | `Quaternion.LookRotation` 指向桌心。禁止凭肉眼调 yaw。靠背比椅座更远离桌心。 |
| 030 升级 | 仅已建成的四人桌 / 方桌出现紫圈。规则、费用、弹窗、套装与 030 相同。柜台与得来速金额不变。 |
| 任务胶囊 | 可提示 `Install a 4-seat table` / `Install a square table`（在现有 `Install a table` 之后）。 |

建议循环：先按日常出餐；走进绿色钱堆圈买四人桌或方桌；需要时再走紫圈选套。

## 界面与资源

- 购买圈：沿用 `ShopExpansion` 绿色地面圆 + 占位金币堆。英文短标 `4-SEAT` / `SQUARE`。已购买则圈消失。
- 圈颜色：绿取餐 / 绿钱堆购买 / 白收银 / 紫升级 / 青雇佣。不挡左下摇杆。
- 四人桌占位：长方形顶、两根桌腿、四把开局款椅（红桌蓝椅，选套后随 030 换色）。
- 方桌占位：更小的正方形顶、四角桌腿、两把**高靠背**椅（靠背带坐垫色块）。选套只换顶与椅垫色，不重建椅、不改朝向。
- 界面语言：英文。禁止 Pizza Ready 素材与商标。
- 参考：同批 TABLE CHANGE 世界里的小方桌 + 钱堆圈只作意图，不进口游戏、不要求像素级复刻。

## 布局（写死，北扩一排，不堵门桌）

厅 ±15。现有 2×2 用餐格 z=7 / z=3；新桌在其北一排 z=**12**，间距 4，过道仍 ≥ 2.5。购买圈落在该桌将出现的位置。

| 物件 | 坐标 | 价格 | 座位数 |
| --- | --- | --- | --- |
| 现有 TABLE 圈 / 两人加桌 | `(-12, 0.02, 3)` / `(-12, 0, 3)` | 150 | 2（不变） |
| 四人购买圈 / 四人桌 | `(-8, 0.02, 12)` / `(-8, 0, 12)` | 200 | 4 |
| 方桌购买圈 / 方桌 | `(-12, 0.02, 12)` / `(-12, 0, 12)` | 150 | 2 |
| 各桌 030 紫圈 | 桌心 + `(1.55, 0.02, 0)` | 80 | — |

不堵入口 `(-12, -6)`、HR 门 `(15, 0)`、Boost 门 `(11, -15)`、z=0 东西过道。

## 与 030 的关系

- 未升级：两种新桌堂食落地均为 **10**，用餐 **3.0** 秒。
- 选 Bistro / Diner / Patio 后，该桌按 030 的 `MealPay` / `EatSeconds` 结算；四人桌是四个座位，每位客人离开时各落一次该桌金额。
- 换套只改颜色，椅朝向断言仍成立。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 钱不够 | 投入停在剩余金额；圈仍在；不出现桌子。 |
| 未买 | 该格只有绿色购买圈，没有桌，没有紫圈。 |
| 已买 | 绿圈消失；桌可用；紫圈出现（未选套前）。 |
| 只买其中一张 | 另一张圈仍在；两桌独立计价。 |
| 切后台 | 不继续投入；恢复后重新 0.3 秒进入等待。 |
| 旧存档 v1–v8 | 两种新桌都未买、投入 0、开局套；旧金币/设施/030 套装保留。 |
| 新存档 | version **9**。`boughtFourSeatTable` / `boughtSquareTable`；购买投入 `fourSeatInvestment` 0–200、`squareTableInvestment` 0–150；套装 `fourSeatSet` / `squareTableSet` 0–3 与升级投入 `fourSeatUpgradeInvestment` / `squareTableUpgradeInvestment` 0–80。套装非 0 时该桌升级投入必须为 80。未买时套装与升级投入必须为 0。 |
| 合法满额未选套 | 读档后补齐待选，不扣第二次 80。 |

不持久化玩家位置或弹窗开关。允许开发自定：桌腿粗细、图标积木、短反馈粒子；不得改 200 / 150 / 座位数 / 圈坐标 / 投入节拍。
