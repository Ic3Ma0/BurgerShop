# BS-SPEC-031：人物与经营动作适度放慢

- 版本：v1.0；状态：待开发产品规格；日期：2026-09-12。
- 用户要求：人物动作慢下来，避免经营完成过快，增加挑战。
- 产品建议：采用以下温和减速，不降低输入响应；不使用全局 TimeScale 调慢所有系统。

## 目标与行为

让走位、搬运和供货有时间成本，同时保留升级和临时加速的价值。先调整速度与作业节奏，不额外延长金币动画、菜单、镜头或存档计时。

- 玩家无临时卡的实际移动速度＝原永久升级后速度 ×0.85；初始 5.5→4.675 世界单位/秒。
- 员工速度＝原永久升级后速度 ×0.85；保留所有已购买等级和各级相对收益。
- 顾客入队、走向座位、离店速度统一为原速度 ×0.80；基础 2.4→1.92 世界单位/秒。车辆不是人物，本次不调车速。
- 玩家与员工拿取、上架、装卸物品的相邻启动间隔统一最低 0.35 秒；原来更慢的间隔不缩短。同一接收点仍共享库存/冷却，不因人数增加绕过已有约束。
- 普通堂食每件交付动画 0.45 秒，抵达后等 0.15 秒再交下一件，即最快每 0.60 秒一件；034 的柜台等级可改善该间隔。
- 原有盒装台基础加工每件 0.35 秒；后续 034 的工作台等级可改善。车辆交付仍保持现有时长。
- 普通顾客用餐由 3 秒改为 5 秒；大胃王 7.5 秒。汉堡机器产出、到客间隔、价格本次不改，先让搬运和桌位成为可感知的瓶颈。
- 摇杆松手立即停止、有效输入立即响应、转向和镜头继续使用已有手感优化。角色移动动画与实际速度匹配；不把迟钝或滑行当作“慢节奏”。

## 边界与兼容

界面速度预览必须取减速后的实际值，永久升级倍率仍有效。032 轮滑鞋在上述最终基础上再乘 1.5；BUFF 消失恢复本版速度，不恢复旧快速度。无需修改永久等级字段；不通过覆盖存档反复乘 0.85。大胃王订单不改变普通客售价。

## 本地验收

1. 同等级相同满杆输入，玩家/员工实际速度为原值 85%，顾客为 80%；读档多次不会继续减速。
2. 小幅移动、急停、对准打包/柜台仍可操作；拿取和服务间隔满足规则，普通客用餐 5 秒。
3. 走完一次生产→上架→服务→收钱→清洁，能继续经营，升级仍变快。只做必要 Play 体验，若出现持续无事可做，记录瓶颈并调整建议，不擅自把全部系统再减速。
