# BS-SPEC-033：侧翼解锁、可乐迁入招聘房后方

- 版本：v1.0
- 状态：可开发 / 开发中
- 对应基线：`feat/shop-rank` 已含 030–032；可乐玩法循环来自 `origin/cursor/cola-product-2c90`（PR #17），本刀合入后**改到侧翼购买**，不叠到可乐专用 PR。
- 优先级与原因：用户要求开阔大侧区、从侧门进入招聘房后方；该后方同时卖可乐、买新桌。侧翼**开局不存在**，先投金币解锁，再进去建造。
- 前置依赖：019 加桌、023 投入圈、026–028 界面、030–032 桌型与碰撞。可乐循环规则对齐 PR #17 的机器/柜台/升级/垃圾，但**开局不再预放**。
- 用户已确认：侧翼开局没有；花钱解锁后扩展到参考图那种大侧区；再引导玩家进去建造可乐机、可乐柜台和新桌。不抄参考游戏名称、Logo、贴图、音频。本云环境未挂上 `ref-cola-wing-*.jpg`（父代理曾复制到其 store）；布局按文字描述与 Pizza Ready **观感**写死，不是像素复制。
- 产品建议或关键未定项：侧翼 **300**；可乐机 **200**（同额外烤台）；可乐柜台 **250**（同额外柜台）；桌价仍 150 / 200 / 150。坐标为 BurgerShop 建议值。

## 目标与范围

玩家目前：30×30 大厅，招聘房贴东墙，加桌圈在用餐区；本分支没有可乐机。

本次之后：

1. 开局东墙只有 HR 门。厅内东北有绿色 `WING` 钱堆圈。
2. 投满 300 后，东墙北侧出现侧门；招聘房**北侧走廊**通向招聘房**东侧后方**的大侧翼。
3. 侧翼内出现绿色 `COLA` / `BAR` / `TABLE` / `4-SEAT` / `SQUARE` 圈。买下后才生成对应家具。可乐循环（绿取货 / 紫升级 / 白收银 / 10 纸币 / 喝完 2 纸团）与 PR #17 相同，只是位置在侧翼。
4. 开局三张堂食桌、汉堡机/柜台、HR、Boost、装箱/得来速**不搬**。加桌圈从用餐区**搬走**，不要留在旧格。

本次交付：

- `ShopLayout` 写死侧翼范围、侧门、可乐与加桌世界坐标。
- `ShopExpansion`：`WING` 圈；解锁后生成侧翼地板/墙并打开侧门；再生成可乐与加桌圈。
- 从 PR #17 合入可乐循环（`KitchenProduct.Cola`、杯视觉、独立白圈节流、员工可乐线），但改为侧翼内购买。
- 碰撞仍贴占位（032）：侧翼墙/地板/可乐机身/柜台挡住玩家；钱堆圈与绿/白/紫圈可走。
- 存档 version **10**。旧档保留金币与已建设施；若旧档已买加桌，免费视为已开侧翼，桌子出现在新坐标。

本次不做：

- Pizza Ready / 披萨品牌、广告、钻石、第二货币、用户 Mac。
- 汉堡+可乐套餐、得来速可乐、第二台付费可乐机。
- 改 030 套装价、031 桌价、开局烤台 30/60、雇佣 50/100/200。
- 离线收益。

## 玩家流程与规则

入口：`SampleScene` Play 后 `Goal01Bootstrap` 组装。侧翼几何与可乐物件开局都不在。

| 项目 | 明确规则 |
| --- | --- |
| 侧翼未买 | 东墙仅 HR 门；`WingDoorPlug` 堵住未来侧门。玩家不能走进侧翼。`WING` 圈在厅内 `(8, 0.02, 8)`。加桌 / 可乐圈不出现。 |
| 解锁侧翼 | 玩家站进 `WING` 圈，投入节拍同 023（进圈 0.3s，之后每 0.1s 最多 10 金币）。**300**。员工不投入。投满：圈消失；拆掉门塞；生成走廊+后方地板与外墙；侧门可走。 |
| 侧门 | 东墙 `x = 15`，`z = 8`，半宽 **1.5**（开口 z 6.5–9.5）。在 HR 门（z=0）**北侧**，不穿过 HR。 |
| 进入路径 | 侧门向东 → 招聘房北侧走廊 → 招聘房东侧后方大开间。HR 四面墙仍在，不能从办公桌穿到侧翼。 |
| 侧翼内购买 | 解锁后才出现绿圈：`COLA` **200**、`BAR` **250**、`TABLE` **150**、`4-SEAT` **200**、`SQUARE` **150**。圈心 = 家具将出现的位置。 |
| 可乐机 | 买下后才有。绿取货圈、紫升级圈。升级与**开局汉堡机**相同：30 / 60，3.0s→2.0s→1.5s，库存 4/6/8，`Look_Lv*`。世界字 `COLA n/max`，满级 `MAX`，不要 `GRILL`。 |
| 可乐柜台 | 买下后才有。可放可卖、无上限、白虚线圈。顾客在此排队买可乐。成交掉 **10** 纸币。与汉堡柜台库存、白圈冷却**独立**。 |
| 携带 | 可乐占用现有食品容量。汉堡只进汉堡柜台，可乐只进 `BAR`。装箱不吃可乐。 |
| 垃圾 | 喝完走 014：每人 2 个大纸团，整桌不可坐。 |
| 员工 | 可乐机与柜台都建成后，员工可取可乐、放到可乐柜台、走可乐白圈。汉堡/可乐缺货同时存在时按批次交替，首次堂食汉堡。 |
| 朝向 | 侧翼内加桌椅 `LookRotation` 朝桌心，靠背在外，扁 Dot > 0.9。 |
| 圈颜色 | 绿取货 / 绿钱堆购买 / 白收银 / 紫升级 / 青雇佣（HR 雇佣 HUD）。不得对调。 |

建议循环：先做汉堡；攒 300 买 `WING`；从侧门进后方；再买 `COLA`/`BAR` 与新桌。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 未买侧翼 | 侧门堵住；走进东墙北段被墙挡住。 |
| 只买侧翼 | 大空地 + 绿圈；还没有可乐机/柜台/加桌。 |
| 只买可乐机 | 可生产可取货；没有可乐顾客队，直到买 `BAR`。 |
| 切后台 | 投入中断；重进再等 0.3s。 |
| 旧档 v1–v9 | 侧翼未买、可乐未买、`colaLevel` 视为 1。金币、汉堡机、雇佣、030/031 桌保留。若已买 TABLE / 4-SEAT / SQUARE，**免费**记为已开侧翼，这些桌生成在上表新坐标（不退款、不扣 300）。 |
| 新存档 | version **10**。`boughtSideWing`、`wingInvestment` 0–300；`boughtColaMachine` / `boughtColaCounter`；`colaMachineInvestment` 0–200、`colaCounterInvestment` 0–250；`colaLevel` 1–3（未买机时必须为 1）。未开侧翼不得已买可乐机/柜台。 |

不持久化可乐库存、手持、顾客、垃圾、玩家位置。允许开发自定：侧翼地板分几块、门框粗细、杯尺寸。不可逆：把侧翼做成开局就有、把可乐留在厨房旧坐标 `(9, 3)` / `(3, 4)`、改圈颜色用途。
