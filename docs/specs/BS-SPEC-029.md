# BS-SPEC-029：店铺等级与阶段目标

- 版本：v1.0；2026-09-12；状态：开发完成，待真机。
- 基线：本地 0.2.1 UI/手感（026–028，分支 `feat/ui-feel-feedback` 未合并）叠在 0.2.0 经营规则上。开发以开工时工作区为准。
- 优先级：P1。用户点选「店铺等级与阶段目标」。
- 前置依赖：013 任务胶囊与星条、019/023 设施投入、024 订单、025 打包与车道、026 星条不挡摇杆、028 任务完成不在读档时重放。
- 用户已确认：本刀做长期店铺等级，把会话任务升成阶段解锁。
- 产品建议：下列档位、目标件数与解锁顺序为 BurgerShop 建议值，不是参考游戏测量值。升档不发金币。

## 目标与范围

玩家目前：左上星条是 `1 + 取餐 + 上架 + 成交` 封顶 15，会话重算；五处扩建垫从开局就可投入。星条很快到顶，不能把经营阶段和下一座设施绑在一起。

本次之后：店铺有等级 1–6。每档有一组可完成目标，星条表示本档已完成目标数。做完本档最后一项后升一档，并开放下一座扩建垫。脏桌/垃圾提示仍可打断胶囊，但不改等级。已买或已开始投入的设施保留，不因新门槛收回。

本次交付：

- 存档字段 `shopRank` / `goalIndex` / `goalProgress`，版本升至 8。
- 星条改为 `Lv.N` + 本档 `n/m`；满级写 `MAX`。
- 任务胶囊优先显示当前档目标；清桌/倒垃圾仍优先。
- 未解锁的扩建垫隐藏且不能投入。升档后出现，价格仍为 150/200/250/150/250。
- 升档用现有成功反馈 `Rank Up!`，不发金币、不全屏锁操作、不读档重放。

本次不做：

- 不改单价、设施总价、投入节奏、员工人数、能力升级价、广告、第二种商品。
- 不做单员工成长、常驻收银、3D 重制。
- 不把星条改回 15 格成交计数。

## 玩家流程与规则

开局 Rank 1。左上 `Lv.1  0/3`，胶囊 `Pick up a burger`。完成该档三项后升到 Rank 2，打包台垫出现。依此类推，Rank 6 为满级，胶囊回到日常经营提示。

| 项目 | 明确规则 |
| --- | --- |
| 档位 | 1–6。Rank 6 无新设施。 |
| 解锁垫 | Rank 1 桌；2 打包；3 加烤台；4 加柜台；5 车道。顺序与 `NextInstallHint` 一致：桌 → BOX → 烤台 → 柜台 → 车道。 |
| Rank 1 目标 | 取汉堡 1；堂食/车道成交 3；建加桌 1。 |
| Rank 2 目标 | 成交 5；建打包台 1。 |
| Rank 3 目标 | 装箱 1；建加烤台 1。 |
| Rank 4 目标 | 成交 5；建加柜台 1。 |
| Rank 5 目标 | 成交 5；建车道 1。 |
| 成交计数 | 只计本项目激活后新增的 `CompletedSales`（含员工），不追溯历史成交。 |
| 星条 | 本档已完成目标数 / 本档目标数。一项目标完成才 +1 星，中间进度只改胶囊 `n/n`。 |
| 升档 | 最后一项完成庆祝 0.6 秒后升档，垫出现，`Rank Up!` 最长 0.90 秒。不发金币。 |
| 打断 | 手上有垃圾或桌脏时胶囊改清桌文案；等级进度仍可在后台因成交推进。 |
| 雇佣/升级房 | 不作为本刀硬目标。满级后才用原雇佣/强化提示。 |
| 价格 | 设施总价与 023 投入不变。 |

旧档（v7 及更早）不读等级字段，按已有设施/投入推断最低档，使已买或已投入的垫仍然可见：

- 已建加桌 → 至少 Rank 2；仅投入未建 → 仍 Rank 1（桌垫本来就开）。
- 已建打包 → 至少 Rank 3；仅投入 → 至少 Rank 2。
- 已建加烤台 → 至少 Rank 4；仅投入 → 至少 Rank 3。
- 已建加柜台 → 至少 Rank 5；仅投入 → 至少 Rank 4。
- 已建车道 → Rank 6；仅投入 → 至少 Rank 5。

推断后的当前档目标从 0 开始，不把旧成交一次性填满。读档不播放完成或升档。

## 界面与资源

- 左上星胶囊保留 026 尺寸与配色。文案 `Lv.N  n/m`，满级 `MAX`。增加时仍 punch。
- 胶囊标题用上表英文。进行中显示该项 `progress/required`。
- 未解锁垫：物体与 Remaining 标签隐藏，不可投入。已投入但按旧档推断应可见的垫保持可见。
- 升档沿用 028 `FeedbackDirector.Success`，文案 `Rank Up!`。不新增全屏面板或付费按钮。
- 英文界面。程序绘制图标，不引入原作素材。
