# BS-SPEC-037 自动外卖链交付

已接入 SampleScene 主汉堡机背部出料、可见移动链板、汉堡逐件运输、蓝色包装隧道、红盒传送链、黄色台自动入库及骑手自动取货。保留主机 1 个库存供堂食/玩家；加工和结算参数不变。传送件有间距，堵塞时逐级停止进料，释放空间后自动恢复。玩家无需搬运，预览出生点移到链外且不再预先塞入手持汉堡。

Unity 6000.3.23f1 外卖测试 8/8 通过，新增无人操作连续结算、64 个物品在满仓链中守恒和恢复测试；记录 Logs/courier/conveyor-results.xml。SampleScene 隔离存档 GUI 实际 Play 已观察到汉堡在线上移动、红盒在线上移动、骑手后架/货斗装入红包、满单骑手沿回程车道离开并留下奖励。玩家保持原地，未参与运输。运行日志 Logs/courier/conveyor-play.log 未发现脚本异常。

传送带是当前程序化模型，弯道采用分段圆角；链条装饰不增加玩家碰撞，保持原有步行通路。共享主机仅保留 1 件库存，不保证不同消费者的产能比例。后续若需要固定产能分配或传送带通行设计，应单列需求。临时在途物品不跨会话保存，存档版本保持 v11，真实存档未用于预览。

本地实现及验证完成；未推送/合并 GitHub、未构建或发布 Android。操作：BurgerShop → Courier preview (isolated save)，可原地观察自动回路。

## 连续链条与奖励拾取修复

用户指出蓝色设备入口/出口断带：已增加 InternalPackagingChain，使内部与两端同高度衔接，出口改为窄支柱留出通道。纸币参考图改为平放三层亮绿钞票堆，浅绿边框及几何货币符号，取消漂浮旋转。现金移除每次到达后的额外等待，启动间隔 0.04 秒、飞行 0.18 秒，支持并发飞行并预留溢出空间；零件同样连续飞入，零件余额沿用拾取启动时入账，现金在到达时入账。

20/20 相关测试通过（Logs/courier/flow-results.xml），其中更新旧版漂浮/逐堆等待断言，新增并发拾取只入账一次的检查。Unity 隔离预览确认蓝色机器内部不再缺少链板；连续拾取主观手感留给用户体验，未声称人工完整拾取验收。未进行 Android 或 GitHub 发布。
