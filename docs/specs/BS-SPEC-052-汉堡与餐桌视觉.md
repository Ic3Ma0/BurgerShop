# BS-SPEC-052：汉堡与餐桌视觉

- 状态：已完成本地 Unity 验证
- 用户确认：“汉堡和桌子的 UI 呢，也同样进行修改”。沿用 BS-SPEC-051 的汉堡餐厅风格。

## 范围与规则

- 汉堡统一为金黄芝麻面包、烤肉饼、融化芝士、生菜和番茄；用于生产、库存、搬运、顾客与传送带的同一食物模型。订单、菜单中的汉堡图标同步。
- 双人桌、四人长桌和高靠背方桌采用圆角桌面、包边、完整支撑、软垫椅和四条椅腿。保留桌型、座位位置与朝向，升级配色继续能区分。
- 桌面加入小型纸巾盒和调味瓶；装饰不占用交互空间，不新增碰撞障碍。
- 保留现有食物堆叠间距、桌椅尺寸、基础碰撞、建造占地、商店购买与移动旋转流程。新增食物外观不生成阻挡碰撞。
- 价格、产量、等级、人数、用餐时间、小费和存档完全沿用现有规则；不新增玩法和持久化字段。本次不改变 T(n)。

## 验收

1. Unity 实际渲染确认汉堡食材完整、堆叠不互穿，三种桌型轮廓与椅子朝向正确。
2. 定向 EditMode 回归覆盖餐桌席位、三选一升级、碰撞、汉堡生产/拾取/顾客消费和材质释放。
3. 新旧桌型在摆放旋转后保留相同的座位坐标关系；桌椅装饰不扩大原有阻挡范围。
