# 088 手持食品丢弃交付

垃圾桶靠近范围沿用 1.25；玩家无餐桌垃圾待处理时，逐件丢弃手持可乐和汉堡。每次间隔沿用垃圾桶配置（默认 0.11 秒），现有食品模型飞向桶口并缩小销毁，复用倒垃圾音效。离开或暂停不继续丢弃，已经在途的模型正常结束。盒装/纸袋/红盒不在本次丢弃范围；员工仍走原倒垃圾 API。

没有变更钱包、升级、订单或存档规则。手持计数通过 BurgerInventory.TryTake 更新，余下物品自动重新堆叠，腾出的容量可用于继续拾取汉堡。

## 验证

隔离 Unity 6000.3.23f1，无图形运行，Spec088FoodDisposalTests + DiningTrashTests 共 15/15 通过：
- 满手 4 杯可乐、满手 4 个汉堡分别验证：先丢 1 个而不是一次全清空，持续靠近后清空，动画模型回收，再从生产设备取到汉堡。
- 远离、零时间推进、禁用垃圾桶均不丢弃；离开后剩余库存不减少，在途动画结束。
- 盒装/袋装/空袋/红盒保持数量。
- 原清桌、餐桌垃圾飞行/计数、垃圾桶大小、倒垃圾声音生成等回归通过。

边界脚本（含 6 个自检）与 git diff --check 通过。没有读取真实玩家存档；本轮未手动观看/听取动画音效，未执行 Android 验收。
