# BS-SPEC-084：点击人物升级

- 版本：v1.0，2026-09-22。
- 状态：已实现，本地定向自动测试与 UI 渲染检查通过；Computer Use 人工操作未完成。
- 用户已确认：玩家和员工升级改为点击人物触发，与设施升级类似；不再走到区域自动弹窗。
- 基线：当前 SampleScene；保留 083 经济修复及其他未提交修改。

## 目标与规则

1. 短按玩家打开 Player upgrades；短按任一已雇员工打开 Staff upgrades，注明作用于全体已雇员工。顾客、骑手不提供本入口。
2. 卡片展示速度/携带的当前等级、下一档能力、费用和缺款；点击对应按钮购买，关闭后继续经营。沿用设施详情的暂停经营、固定相机和遮罩交互。
3. 取消玩家升级点及 HR 附近的自动升级弹窗，购买不再要求玩家站在旧区域；HR 的雇用流程保持原样。
4. 复用设施的短按判定：拖动、长按、摇杆、UI、多指和商城摆放不触发。一次手势只选择一个最近可见对象，不穿过墙/柜台选择人物，不为选中员工增加物理碰撞。按下时捕获人物身份，在短按有效范围内即使员工走动也能正确打开其卡片。
5. 投资提示指向当前人物，提示点击人物；点击投资胶囊也打开相应卡片，不再带去旧升级点。
6. 价格、20 档能力曲线、星奖励、员工属性全体共享及原解锁条件保持不变。不新增存档字段，旧等级照常生效。无员工不能购买员工属性。重复回调、旧等级确认、隐藏卡片不扣钱。

## 节奏与范围

本次只替换升级入口，减少绕路和误弹窗；不新增成长线、不改变金币目标及收入参数。经营时钟暂停与设施详情一致，攒钱所需经营时间没有数值调整，实际节省的操作耗时未测量。不触碰广告、长期等级或离线规则。

## 技术边界与方案审查

- 归属与复用：设施和人物共用 WorldDetailsInput 的指针判定与命中排序；FacilityDetailsHud 继续负责设施卡片。PlayerUpgradeHud/StaffUpgradeHud 复用 StatUpgradePopup，改为显式打开。
- 状态归属：StatUpgradePopup 只拥有当前属性卡的可见状态及暂停恢复；等级仍唯一归 BoostUpgradeZone/StaffUpgradeBoard，金币归 RestaurantWallet。员工卡不创造单人员工等级。
- 依赖方向：输入选择目标 → HUD 展示/请求购买 → 既有升级所有者校验和原子扣费；指引只读取目标和等级。外观只提供选择所需的渲染边界，不改碰撞和寻路。
- 兼容与失败：保持存档结构；关闭、禁用、销毁卡片均恢复此前时间速度和相机状态。范围检查由显式入口替代，等级快照和购买重入校验保护连续点击；资金不足不改状态。
- 自动防线：替换已被新规格改变的“靠近打开/离开关闭”断言；定向验证鼠标/触屏点人、拖动/摇杆/UI/多指拦截、无跨对象误选、共享员工属性、扣款/星/重载及设施回归；运行 `bash scripts/check-boundaries.sh --spec docs/specs/BS-SPEC-084-点击人物升级.md`。

## 验收

- AC-01：走到旧玩家点与 HR，升级卡不自动出现；短按玩家/员工打开对应卡；任意位置可升级。
- AC-02：开卡暂停且阻挡背景操作；关闭/Escape/禁用恢复原时间速度和相机，单次点击不会同时打开设施卡。
- AC-03：保留实际费用、速度/携带效果及 +2 星；员工升级作用所有已雇员工；无员工、余额不足、旧等级请求及重入不扣款。
- AC-04：拖动、长按、多指、摇杆和摆放不弹卡；客户不弹卡；被墙挡住的人物不可点击。
- AC-05：投资提示不指向旧升级区；手机竖屏与桌面横屏卡片文字和按钮完整可见；旧档等级保留。
