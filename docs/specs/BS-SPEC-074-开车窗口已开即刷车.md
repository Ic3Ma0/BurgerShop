# BS-SPEC-074：开车窗口已开即刷车

- 版本：v1.0
- 状态：**已完成**
- 开发时基线（历史）：本地 `main` + 未提交 057–073；开车循环沿用 022/046/073；厢房见 064；等级表见 069；点击晋级见 070
- 优先级：Rank 6 任务是 Complete a drive-thru order；南侧汽车厢和临路窗口已经在世界上，但车道上没车，玩家无法交货
- 前置：073 把刷车绑在「已买开车柜台 / 世界 LANE」；064 汽车厢在 Rank 5 打开；069 Rank 6 = `CarOrder`
- 用户已确认：不改价、不加新车型、不改 069 两张起步桌、不改 070 点击、不改 071 室内 Walk、不改 072 柜台叠高与烤台 5/8/12。窗口已开时不要再逼买一件不好找的超市 SKU
- 产品建议或关键未定项：无。本文件修正 073 的购买门槛：Rank ≥ 6 且开车窗口/汽车厢已在世界上 → 必须刷车

## 目标与范围

073 修好了「装箱包装柜假冒已拥有开车柜台」和南街地块过窄，但仍要求再买 `LANE` / 超市 Drive-thru counter。试玩截图：Lv.6 0/14、Complete a drive-thru order 0/1、97 金币，人站在南侧格子地板厢房里，红雨棚对着深色马路，路上没有车。064 厢房在 Rank 5 已开；车道价 250，玩家只有 97，超市垫块还被 `SetStoreOnly` 藏掉。购买门槛把 Rank 6 锁死。

本次交付：Rank ≥ 6 且汽车厢或临路开车窗口已在世界上（064 厢房、已买装箱/开车、或截图里那间凸出临街房）时，创建并 `SetOpen(true)` `DriveThruLane`，车沿窗口对着的那条深色南街生成。交货仍要蓝盒；刷车不要求包装柜已有货。

本次不做：改售价、新车型、072、069 桌数、070 点击、071 堂食 Walk、Android、全局调价、恢复 Lv.13 存档。

## 玩家价值与成长衔接

- 玩家当前：会打蓝盒、点 Upgrade 进 Rank 6，人已经站在开车窗口房里。证据是任务停在开车单、窗外马路空着。
- 现实：窗口开张就会来车。本作不再要求窗口已经砌好之后再买一块看不见的车道垫。
- 解锁：Rank 5 开厢并卖装箱；Rank 6 打开刷车。装箱台仍是 Rank 5 那笔 150，需要打包时去买/使用；不是刷车的第二道门锁。
- 对经济：不改 150/250 与每件 15。超市仍可卖额外开车柜台（第二台起按既有重复价）。修好后 Rank 6 不再死等（I2）。

## 经济与节奏依据

- 不改装箱 150、车道标价 250、开车每件 15、`StarCap(6)=14`、CycleCost、烤台/柜台参数。
- T(n) 不因本次改变；只消除「窗口已开、任务要开车、系统不生成车」。
- 自动开车道不扣 250。那笔钱只用于自愿再摆一台自定义开车柜台。

## 玩家流程与规则

| 项目 | 明确规则 |
| --- | --- |
| 生成条件 | **同时**满足：① Rank ≥ 6（或旧档 `LegacyAccess`）；② 开车窗口/汽车厢已在世界上（064 Rank 5 厢房、已买装箱或开车、或临路红棚窗口）。不要求再买 `LANE` / 超市 Drive-thru counter。不要求包装柜已有蓝盒；没货时车在窗口等。 |
| 自动开车道 | Rank ≥ 6 且②成立时：南门保持打开、创建或启用 `DriveThruLane`、`SetOpen(true)`、绑定已有装箱台、开始按现有间隔生成。世界 `LANE` 垫块视为已建成（不再收 250）。不得只开厢房却没有车道组件。 |
| 与 073 的关系 | 073 的「必须先买开车柜台才刷车」废止。买 `LANE` 或超市第一台 Drive-thru 仍可开车道，但是冗余，不是 Rank 6 的必做项。装箱包装柜仍不得在车道创建前假冒已拥有 `CarCounter`。 |
| 车辆动线 | 车走窗口对着的那条深色南街（`StreetEnvironment.SouthStreet`，z≈−30），spawn → 窗口队列 → 离场，用车道自身坐标，**不**走堂食 `ShopLayout.Walk`，也**不**刷到镜头外的另一条南带。最多 3 辆、停窗口、无货不离，规则同 022。 |
| Rank 5 | 汽车厢可按 064 打开，**不刷车**。 |
| 成交 | 窗口交一单仍 `RecordMilestone(CarOrder)`，070 补满星星并出现 Upgrade。玩家操作：在装箱台打蓝盒 → 放到包装柜 → 站窗口绿圈交给停着的车。 |
| 费用 | 不改价。自动开车道不扣款。 |
| 存档 | Rank 6 且厢房已开、即使 `boughtDriveThru` 为假，读档后也必须 `Create`/`SetOpen` 并刷车。不新增存档字段；之后 `HasDriveThru` 为真则照常写入。 |

| 情况 | 预期行为 |
| --- | --- |
| Rank 5，厢房已开 | 不刷车 |
| Rank 6，厢房/窗口已开，未买 LANE | 车道启用并刷车 |
