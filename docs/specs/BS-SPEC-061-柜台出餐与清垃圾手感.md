# BS-SPEC-061：柜台出餐与清垃圾手感

- 版本：v1.0
- 状态：已完成，本地定向验证通过；已纳入本地提交 `0e93618`
- 开发时基线（历史）：本地 main + 未提交 057–060；不改经营数值、不加存档字段
- 用户确认：出餐要从柜台上的汉堡飞向顾客；柜台堆要随补货增高；倒垃圾要更快、有音效、垃圾桶更大；去掉挡住视线的 Serve/Waiting 提示条
- 前置：无

## 目标

出餐时顾客必须接过柜台上那一只汉堡，而不是从汉堡机或世界原点凭空出现一只。持续补货时柜台实物要继续堆高（分列，避免一根柱子顶到屋顶）。倒垃圾要听得见、扔得快、桶够认。柜台旁不再弹出 Serve / Waiting 提示条。

本次不做：改售价或收入、新存档字段、缩短共用的桌面拾取/收钱飞行动画、Android。

## 规则

### 出餐手递

- 逻辑仍从 `CounterStock` 扣 1。飞向顾客的必须是柜面上那只模型：从它的世界坐标起步，不得在原点或烤台再生成一只。
- 可乐柜台走同一套取出；打包柜台 `TryTakeBoxed` 同样交还原位上的盒子。
- 补货时每只都留在柜面。取消「超过 8 只就销毁模型、取出时再新建」的上限。数量角标仍显示总数。
- 柜面按列摆放：每列约 6 只，多出来的往旁边开新列，避免单柱穿过屋顶。

### 倒垃圾

- 桌面拾取、地上收钱仍用 `TrashMotion.Duration`（0.35s）。
- 只有倒进垃圾桶的飞行更短（约 0.16s），仍带可见抛弧。
- 连倒间隔约 0.10–0.12s，不再被 `max(0.35, interval)` 卡住。
- 倒出时播放独立程序音（纸屑摩擦 + 闷响），走现有 Sound On/Off。
- 垃圾桶 3D 放大约 1.6–1.8 倍，投入口高度跟着抬；携带 HUD 的垃圾图标与食物图标一样可读。

### Serve/Waiting 提示

- 不再创建或显示 `ActionHint`（Serve / Waiting / Stock / Collect / Packing 条）。出餐、补货、收钱玩法不变。
