# BS-SPEC-021：HR 房间员工升级

- 版本：v1.1
- 状态：已实现（Editor EditMode 通过；未做 vivo 真机）
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-017](BS-SPEC-017.md) HR 雇佣与 [BS-SPEC-020](BS-SPEC-020.md) 玩家强化房之上
- 优先级与原因：用户已批准员工也可升级，但入口只在 HR 房间；靠近后弹出强化框，两点选立刻扣款加属性。
- 前置依赖：017 的 HR 房与桌边 1.5s 雇佣；020 的玩家五档价格表（50 / 150 / 300 / 450 / 600）与同一套弹窗。019 厅内解锁圈并行，不得回滚。
- 用户已确认：本刀已批准。不要 1.5s 站立购买员工升级；改为点击。右上角 **X** 可关窗、不强化。禁止 Pizza Ready 素材。
- 产品建议或关键未定项：英文只用 `Staff upgrades` / `Speed` / `Carry` / `MAX`。玩家框标题是 `Player upgrades`（020），**不要写成 Staff**。玩家移速与携带由 020 管理，**不与员工档位共用计数**。

## 目标与范围

玩家目前是：走进东侧 HR 房，在桌边停留 1.5s 按 50 / 100 / 200 雇人。员工开局移速 3.8、一次携带 2。南侧强化房只改**当前玩家**。

本次之后：玩家走进 HR（进门或靠近办公桌）即弹出 uGUI 强化框。两个独立按钮：**Speed**、**Carry**。各 5 档，价格与玩家强化一致。点一下：钱够则扣该档价格并立刻 +1 档；框可留着继续点另一项或下一级。钱不够按钮灰；满级显示 MAX。离开 HR 范围关窗。属性对所有已雇员工生效，之后新雇的也吃当前档。

本次交付：

- HR 房间范围内弹出居中偏上的英文强化框；仅 Speed / Carry / X 的 `raycastTarget=true`，其余 false。不挡左下摇杆。
- Speed / Carry 各 5 档，价格 **50、150、300、450、600**（按钮写下一档价格）。点击购买，不走 1.5s 停留。
- 速度：以员工开局 3.8 为基数，每档 **+15%**；满级 1.75×（6.65）。
- 携带：开局仍 **2**（`RestaurantWorker` 创建时 `Configure(2)`）；每档 **+1**，满级 **7**。
- 存档升版本；`staffSpeedTier` / `staffCarryTier` 0–5。旧档视为 0。
- 玩家自己的速度 / 携带仍由 020 `playerSpeedTier` / `playerCarryTier`（旧档 `boostLevel` 迁移）管。

本次不做：

- 不改 017 的桌边 1.5s 雇佣、50 / 100 / 200、最多 3 人。
- 不回滚 020 强化房、019 解锁圈、1.5× 场地、纸币落地、烤台 30/60。
- 不把员工档位写进玩家强化房，也不把玩家档位写进 HR。
- 不引入 Pizza Ready / Kingshot / Doughnut 名称、立绘或截图。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装。强化框挂在 `JoystickCanvas/SafeArea`。

| 项目 | 明确规则 |
| --- | --- |
| 弹出 | 玩家进入 HR 房间（`ContainsHrOffice`）或站在东墙门洞内（`ContainsHrUpgradeRange`，含 `x≈15, z≈0` 门缝）。靠近办公桌也算在房间内。 |
| 关闭 | 离开上述 HR 范围立刻关窗。点右上角 **X** 也关窗、不扣钱；仍站在 HR 内则保持关闭，离开再进才再弹出。站在主厅、南侧 Boost 房或解锁圈不弹员工框。 |
| 购买 | 点 **Speed** 或 **Carry** 一次升该条 1 档。钱够则扣款并立刻生效。框不关，可接着点另一条或同一条的下一档。 |
| 价格 | 档 0→1：**50**；1→2：**150**；2→3：**300**；3→4：**450**；4→5：**600**。与 020 玩家强化价目相同，计数分开。 |
| 钱不够 | 该按钮灰、不可点、不扣款。另一条若付得起仍可点。 |
| 满级 | 该按钮显示 `MAX`，不可点。 |
| 速度 | 开局 `3.8`。公式：`3.8 × (1 + 0.15 × 档位)`。档 0–5：`3.8 / 4.37 / 4.94 / 5.51 / 6.08 / 6.65`。 |
| 携带 | 开局 **2**（现有员工创建值）。公式：`2 + 档位`。档 0–5：`2 / 3 / 4 / 5 / 6 / 7`。 |
| 作用范围 | 已在场的全部员工立刻改；之后新雇的按当前两档生成。未雇人时也可先买档。 |
| 玩家 | 玩家移速仍开局 5.5、携带仍开局 4，只受 020 玩家两档影响。南侧框标题是 `Player upgrades`，不是本框。 |
| 雇佣 | 桌边停留雇人规则不变。升级不再要求 1.5s 站立。 |

建议循环：先赚钱，走进 HR 雇人或点 Speed / Carry；员工立刻更快或一次多拿汉堡。

## 界面与资源

- 弹窗：居中偏上（约 1080×1920 参考坐标锚点中心、上移，不落入摇杆 keepout）。标题 `Staff upgrades`。左 **Speed**、右 **Carry**，右上角 **X**，按钮写名称 + 下一档金币或 `MAX`。
- Speed / Carry / X 的 `raycastTarget=true`；底板、标题、按钮文字及其它 Graphic 为 false。隐藏时 `blocksRaycasts=false`。
- 资源：运行时 uGUI + `HudChrome`。与 020 共用 `StatUpgradePopup`（玩家标题 `Player upgrades`）。禁止 Pizza Ready 素材与商标文案。

允许开发自行决定的可逆细节：按钮配色、框宽高像素（不得挡摇杆、不得改价格与公式）。
