## 目标与范围

玩家目前看到顾客从街道进店时斜着抄转角（45° 滑过门口），进门后又在过道上来回走两遍才去柜台排队。这是路径 bug，不是新玩法。063 已规定室外 → 转角 → 门口 → 店内入口 → 排队位、不得穿墙；065 规定绕柜台走 z=0、禁止 null 冻住。本次只修正：正交折线、进门后一条路走到队尾/柜台位、拼接进店路时去掉重复前缀。

本次交付：

- 室外 → 门口 → 过道：相邻路段只沿 X 或只沿 Z（已近似轴对齐的除外），不走斜边
- 顾客已过门 / 已在室内后，剩余路径是**一条**到排队槽的路：不沿同一过道段先正后反（超过转角余量），不把门廊或过道走两遍
- 仍不穿柜台体积；仍走现有南墙大门

本次不做：改售价/客流/等级桌数、061 出餐手感、070 点击升级、068 槽位、新存档字段、Android、为员工三线另做寻路（除非同一 `Walk` 修复顺带解决）

## 玩家流程与规则

| 项目 | 明确规则 |

| 过道 | 绕柜仍可走 z=0；不得为了进队而先走到过道原点再折回门口或队尾 |
| 费用 | 不改 |
