# BS-SPEC-026：可乐机、可乐柜台与用餐垃圾

- 版本：v1.0
- 状态：可开发
- 对应基线：已验收 0.2.0（GitHub `main`，PR #15）；本刀从 `main` 开工，不叠 `feat/shop-rank` / PR #16
- 优先级与原因：用户要求第二种堂食商品，循环与汉堡对称：生产机 → 绿区取货 → 柜台放货 → 白圈出货 → 入座饮用 → 留下与汉堡相同的垃圾
- 前置依赖：013 柜台/桌子/白圈；014 用餐垃圾；015 员工清桌与共享库存；018 升级反馈；019 开局烤台升级标准（30/60、库存 4/6/8、`Look_Lv*`）
- 用户已确认：可乐机、可乐柜台、升级标准与汉堡机相同、喝完产生与汉堡相同垃圾。本文件把上述规则写死。
- 产品建议或关键未定项：开局即有一台可乐机 + 一个可乐柜台（对标开局烤台/柜台，不是 019 的付费额外机）。可乐成交价与汉堡相同（10 纸币）。员工把可乐当作第三条供货线，与堂食汉堡、装箱轮转。坐标由开发按现有 30×30 厅与过道写死，见布局表。

## 目标与范围

玩家目前只有汉堡堂食循环。本次之后店里多一条平行的可乐循环：可乐机产出杯子 → 绿色取货圈拿走 → 放到可乐柜台 → 顾客在可乐柜台排队 → 白圈从柜台出可乐（掉 10 纸币）→ 顾客入座喝约 3 秒 → 该桌留下正好 2 个大纸团，清桌规则与汉堡用餐相同。

希望解决：只有一种堂食商品、升级与垃圾循环无法套用到第二产品。

本次交付：

- 开局一台可乐机：独立库存、绿色取货圈、紫色升级圈。升级标准与**开局汉堡机**相同（不是额外汉堡机的 80/160）。
- 开局一个可乐柜台：可放可卖、库存无上限、柜台旁白色虚线圈。顾客在此买可乐，不与汉堡柜台混库存。
- 可乐占用玩家/员工现有食品携带容量（与散装/盒装合计），不另开背包。
- 玩家与员工共享该可乐机库存、该可乐柜台库存、以及该白圈的收银节流；额外搬运者不能靠连点跳过间隔。
- 喝完可乐走 014 同一套垃圾：每人正好 2 个大纸团、整桌不可坐、飞向玩家/桶。
- 任务胶囊英文：`Pick up a cola` / `Move to cola counter` / `Serve a cola customer`。携带 HUD 可出现 `COLA n`。
- 存档升到 version **8**：只持久化可乐机等级。旧档视为 LV1。柜台库存、手持、顾客、垃圾仍是会话状态。

本次不做：

- 不新增付费「第二台可乐机 / 第二可乐柜台」解锁圈。
- 不把可乐并进汉堡订单、不做汉堡+可乐套餐、不改得来速/装箱规则。
- 不改汉堡单价 10、开局烤台 30/60、额外烤台 80/160、雇佣 50/100/200、用餐 3 秒、每人 2 垃圾。
- 不引入 Pizza Ready 名称、截图、模型、音效或商标文案；游戏内英文不得出现 pizza / soda 品牌名。
- 不改摇杆、`SafeAreaFitter`、离线收益。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` 组装。可乐机与可乐柜台开局即存在。

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 可乐机有货且玩家/员工在绿圈、食品容量未满 → 每 0.25 秒取 1 杯。手持可乐且在可乐柜台放货范围 → 每 0.25 秒放 1 杯到柜台。人在可乐白圈内、柜台有货、队首已点单、该白圈冷却结束 → 从柜台出 1 杯。顾客拿到其订单全部可乐后入座，喝约 3 秒，留下 2 个纸团。 |
| 费用 / 奖励 / 时长 / 上限 | 出餐掉 **10** 纸币（走过才入账）。可乐机 LV1 **3.0s**/杯、库存 **4**；花 **30** 升 LV2（**2.0s**、库存 **6**）；再花 **60** 升 LV3（**1.5s**、库存 **8**）。紫色圈停留 **1.5s**，每次进入只升 1 级。满级静态 `MAX`，再停留不扣钱。可乐柜台**无上限**。可乐订单数量权重与堂食汉堡相同（1–4）。用餐 **3** 秒。垃圾每人 **2** 个。食品总携带仍为当前容量（开局玩家 4）。收银间隔与汉堡白圈同一套（交接 **0.35s**，件间隔 **0.15s**），但**只在可乐白圈内共享**，不占用汉堡白圈的冷却。 |
| 状态变化 | 取货：机库存 −1，手持可乐 +1。放货：手持 −1，可乐柜台 +1。出餐：柜台 −1，队首进度 +1；订单完成则成交 +1、柜台旁掉 10 纸币、顾客去桌子。喝完：销毁杯视觉，该桌 +2 纸团，整桌不可坐。 |
| 与已有功能的关系 | 可乐机与汉堡机**不共享**库存。可乐柜台与汉堡柜台**不共享**库存。玩家与员工共享**这一台**可乐机和**这一个**可乐柜台，以及可乐白圈节流。钱包、桌子、垃圾桶、员工清桌共用。装箱只吃散装汉堡，不吃可乐。汉堡循环、019 额外机/柜、装箱/得来速不变。 |

建议循环（写死）：

1. 可乐机产出，站上绿色取货圈，杯子进食品栏（与汉堡合计占用容量）。
2. 走到可乐柜台放下（柜台数字增加）。
3. 顾客在可乐柜台前排队点单（最多 3 人占位）。
4. 站进白色虚线圈：柜台有货且队首就绪时交出 1 杯，掉 10 纸币。
5. 顾客入座喝约 3 秒，留下 2 个大纸团后离场；清桌/投桶规则同 014 / 015。

员工：可被派去取可乐、放到可乐柜台、在可乐白圈出货。不得把可乐放到汉堡柜台或装箱台。堂食汉堡缺货与可乐缺货同时存在时，散装/可乐补货按批次交替，首次堂食汉堡；单批不超过该员工容量与缺口。有就绪可乐订单且该柜台有货时，须能出货，不能只补货。

## 界面与资源

- 可乐机世界字：`COLA n/max`，满级再写 `MAX`，不要 `FULL`，不要写 `GRILL`。
- 紫色圈外标：未满级 `UPGRADE` + 价格；满级 `COLA LV 3` + `MAX LEVEL`。圈内右下升级面板用 `COLA LV`（不要 `GRILL LV`）。
- 绿色取货圈、白色收银虚线圈、紫色升级圈：颜色用途与汉堡相同（绿取货 / 白收银 / 紫升级）。
- 杯视觉：运行时圆柱杯身（可乐红）+ 白条 + 吸管；柜台徽章同款。禁止易拉罐品牌图。
- 任务胶囊（英文）：

| 当场状态 | 任务文案 |
| --- | --- |
| 手持可乐 ≥ 1 | `Move to cola counter` |
| 可乐柜台有货且可乐队首就绪 | `Serve a cola customer` |
| 可乐柜台有货、顾客未就绪 | `Wait at the cola counter` |
| 空手且可乐机有货、不必立刻做汉堡循环中的更高优先级项 | `Pick up a cola` |
| 脏桌 / 手持垃圾 / 雇佣 / 安装 / 装箱 / 得来速 | 仍优先 013–025 既有文案 |

- 携带 HUD：可在汉堡行下增加 `COLA n`（无分母；容量已算进食品栏）。默认屏仍不挡左下摇杆。
- 资源：运行时 primitive + `RuntimeMaterials`。禁止 Pizza Ready 素材。

## 布局（写死，厨房 +X、不堵门桌）

## 可乐机外观与产能（与开局汉堡机同一套标准）

| 等级 | 价格 | 产能 | 库存上限 | 外观（相对上一级至少两项巨变；套件名 `Look_Lv*`） |
| --- | ---: | --- | ---: | --- |
| LV1 | 初始 | **3.0s**/杯 | **4** | 小蓝柜、单层杯槽、无烟囱、1 灯；根 scale **1** |
| LV2 | **30** | **2.0s**/杯 | **6** | 根 scale **1.22**、杯槽 **2** 层、**1** 烟囱、2 灯 |
| LV3 | **60** | **1.5s**/杯 | **8** | 根 scale **1.45**、杯槽 **3** 层、**双**烟囱、4 灯+信标 |

升级瞬间：工位短震动+放大、弹出 `LV2` / `LV3`；满级静态 `MAX`。读档只显示当前套，不播动画。每次进入圈最多升 1 级。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 可乐机空 / 不在绿圈 / 食品栏满 | 不取货 |
| 手持无可乐 / 不在放货范围 | 不放到可乐柜台；汉堡柜台不接受可乐 |
| 可乐柜台空或人在白圈外 | 不出货 |
| 队首未点单 | 不出货；杯子留在柜台 |
| 玩家与员工同时在可乐白圈 | 同一时刻只出 1 杯；第二人不能推进冷却 |
| 汉堡白圈与可乐白圈 | 两套节流独立；卖汉堡不占用可乐冷却，反之亦然 |
| 手持同时有汉堡和可乐 | 汉堡只进汉堡柜台，可乐只进可乐柜台；容量合计计算 |
| 钱不够升级 / 离开紫圈 | 不扣款、不计时清零 |
| 已满级 | 静态 MAX，不扣钱 |
| 喝完 | 与汉堡相同：2 纸团、整桌不可坐 |
| 切后台 / 重开 | 恢复金币、成交、汉堡机等级、雇佣、员工统计、019–023 设施与投入、**可乐机等级**。可乐库存、柜台、手持、顾客、垃圾重建 |
| 旧存档 version ≤ 7 | 可乐机视为 LV1；既有金币与进度保留；下次写入 version 8 |

存档新字段：`colaLevel`（1–3）。不持久化可乐库存。

允许开发自行决定的可逆细节：杯身圆柱尺寸与吸管角度、可乐柜台材质蓝灰、员工在汉堡/可乐之间的寻路点。不可逆：改价、改垃圾数量、让两套白圈共享一个冷却、把可乐塞进汉堡订单。
