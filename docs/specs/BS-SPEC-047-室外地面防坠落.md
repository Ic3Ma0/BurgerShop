# BS-SPEC-047 室外地面防坠落

用户确认行为：人物走到门前、人行道、草地和道路时不能掉下去。

原因：室外背景只有渲染，没有地面碰撞；大门开放后人物可以离开原有地板。

实现：给有限街区（X -42..52，Z -40..54）添加连续地面支撑，并为人行道和道路补齐高度匹配的碰撞。街区外围设置阻挡，远景继续只用于显示。地面支撑不加入商城的可建造区域，不改变价格、产能、等级或存档。

验收：真实 CharacterController 走过门前地板末端、草地/人行道接缝、汽车与骑手道路不下坠；四边不能走出支撑范围。沿用大门与道路回归。经济节奏项不适用。

## 本地验证

隔离 Unity 项目 StreetEnvironmentTests 7/7 通过（Logs/spec047/verified.xml）。角色控制器以固定步长穿过四处接缝并尝试穿越四条外边界；大门、主道及不同画幅镜头检查通过。测试用固定步长的 CharacterController.Move，避免测试运行器帧时间影响 SimpleMove。未改真实存档，未执行 Android 构建。
