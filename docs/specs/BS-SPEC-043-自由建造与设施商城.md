# BS-SPEC-043 自由建造与设施商城

日期：2026-09-13。用户授权：商城选购全部经营设施、自定义摆放与旋转、移动既有设施；明确允许同类重复购买，受空间和金币限制。
状态：开发中；用户已确认车辆柜台与车道一起重新布局。基线：042本地版本，358项EditMode通过。

## 玩家流程

右上角金币旁购物车打开商城，列出当前已解锁的设施，显示3D外观/名称/本次价格。商城有购买与整理已有设施两种操作。选购后进入3D摆放预览，鼠标射线落在已开放地面上，按住场景拖动模型，松手固定预览；旋转按钮调整15度（Q/E为桌面辅助），Done确认放置并退出，Cancel/ESC撤销。移除Place，不再左键直接确认或悬停跟随；触屏无需键盘。

选购阶段不扣钱；位置合法且再次检查金币和解锁后，确认扣款并生成一个实例，立即保存。取消、无效位置、重复确认不扣费或重复生成。已有设施移动旋转免费，取消回到原位。编辑期间暂停经营模拟，结束恢复此前暂停状态；暂停不停止摆放输入。

## 范围与商品

餐桌：双人、四人、方桌。生产：汉堡机、可乐机、空纸袋机。加工：蓝盒打包台、红盒包装机、纸袋装餐台。交付：汉堡柜台、可乐柜台、汽车柜台、纸袋柜台、黄色骑手取餐箱。清理：垃圾桶。

玩家、员工、顾客、汽车、骑手、货物、现金与零件不是购买摆放的家具。HR/属性房间、外墙和地块属于建筑空间；本次不提供拆墙或免费开地。传送带属于红盒自动化连接设施，需要随端点重新校验，不把它当成可以任意断开的装饰。

同类设施允许重复购买，不沿用旧单例数量限制；有效空间是实际数量约束。库存、等级、购买次序、位置、角度均按实例记录。现有等级、价格和产能升级公式保持。

## 合法摆放

校验整个旋转后的占地及工作区，不只验证中心点。范围必须完全位于已开放、可摆放地面；不得跨未购地块、外墙、道路边界或穿过房间墙体。不得与设施、墙、预留入口、其他设施工作区重叠。

检查玩家可通行宽度及通路连通性：入口、玩家当前位置、HR入口、升级入口、各设施操作点和顾客交付/座位点必须仍可达。预览绿色可放，红色禁止，并说明越界、重叠、通道被堵或服务连接无效。不可只依靠最后把角色夹回地图。

汽车和骑手交付点还需与对应道路形成有效连接；没有车辆能到达的点不能确认。传送带随端点更新，连接路线合法才确认。摆放不会把未解锁道路/产线带进已开放大厅。

## 设施功能与保存

模型、碰撞、生产出口、取放点、升级点、库存堆叠点、收银点、座位、垃圾点、队列和寻路均使用实例位置与朝向，不留下原坐标“幽灵交互”。员工从可达设施中选择任务，保持现有共享库存/收银限流原则。

重定位要同步处理已占座/交付/运输中的对象，不能复制货物或丢掉已付款进度；不以清档或清空全部订单作为移动实现。保存包含唯一ID、类型、合法位置、朝向及持久等级，升级存档格式。旧设施生成稳定ID，按原位置导入，保存后再次载入不重复生成。对非法、重复、NaN/Infinity/越界记录拒绝应用并保留原存档，不自动覆盖成新档。

## 验收

- 购买两台同类设施，价格正确、独立运行，取消与失败不扣款。
- 移动/旋转已有机器和柜台后，玩家、员工、顾客仍从新位置完成整条订单；餐桌座位与垃圾跟随。
- 边缘、旋转角、跨墙、未购侧翼、堵门、重叠、无车道连接均禁止；合法位置可确认。
- 存档往返保留所有实例和升级，旧存档兼容，重复读取不增殖。
- 核心几何/交易/保存EditMode测试，以及SampleScene实际购买、旋转、取消、搬迁后的经营检查。Android仍后续统一验收。

## 节奏契约

服务金币投入的比率时钟和布局规划的开放回路；新能力直接改变既有搬运距离和供货能力，不新增货币。购买下一件T(n)=金币缺口/实际收入率；布局和额外产能影响分母，实际秒数待实测，不以价格公式冒充手感证据。没有建造等待、没有广告或人为数量MAX；资金不足仍可经营，空间不足可免费重排。基础流程保留，不能靠新商城强制重买旧设施。

### 道路重新布局（用户已确认）

汽车柜台与骑手取餐箱不固定在旧车道位置；各自道路、入口、排队位、停靠点、离开路径和路面标记随布局同步移动/旋转。柜台与道路一起预览，完整路面及转弯占地必须位于当前开放空间、避开其他设施并保留步行通路；不能只移动柜台而把车辆留在旧位置。默认以现有道路形态作为起点，路径重排后几何与车辆使用同一份坐标来源。

实现与验证已并入当前自由建造交付记录。道路使用整体相对坐标，校验完整路宽和端部，而不是只检查柜台中心。形状仍沿用现有车道，不提供单独拖动每个道路节点的编辑器。

## 手机摆放确认修订（用户反馈授权）

移除Place按钮；Done是唯一确认放置并退出的按钮，位置非法则保留预览并显示原因。场景按下/拖动调整预览，松手固定位置；鼠标悬停、触摸旋转/取消/Done及工具栏区域不改变预览位置。在UI开始的手势即使滑出UI也不拖动物品。旋转按钮直接可用，Q/E仅作为桌面辅助。Cancel仍取消且不扣钱。

预览颜色与确认统一：绿色必须完成与Done相同的空间/通路检查；待检查为黄色，非法为红色。摆放前后通路采用同一障碍模型比较，不能把已有差异误算作新阻断。错误后仍可继续拖动、旋转或取消。

## Unity Play 对齐用户认可的桌面预览（用户授权）

桌面鼠标采用BurgerShop Placement Preview的操作：模型跟随鼠标移动，Q/E或按钮旋转，点击场景确认落地并保留整理模式，Done结束；有未放置模型时Done仍可确认。指针进入UI不更新模型位置。手机触屏继续使用拖动、松手固定、Done确认。边界/通路完整校验和实例存档修复继续保留，不回退整个项目。
