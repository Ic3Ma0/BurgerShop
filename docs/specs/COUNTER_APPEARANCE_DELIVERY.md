# 柜台等级外观

用户确认：升级后柜台模型每级明显不同，不增加常驻提示或重新设计操作面板。

- Lv1：基础面板、商品配色台沿。
- Lv2：彩色柜面、金属包边、抽屉、收银机和屏幕。
- Lv3：金色台沿、背部立柱、顶棚、灯带及商品标识。
- 汉堡柜台/额外柜台：各自 ServiceLevel。
- 可乐柜台：跟随可乐机等级（现有可乐柜台没有独立升级购买）。
- 打包工作台、打包柜台、车道窗口：跟随 BoxingStation.WorkLevel。
- 西区装袋台、PICKUP 柜台：各自已有等级。

未新增升级收费或更改产能、存档结构。新部件没有碰撞，不移动库存锚点及操作圈。重复设置同一级不重复生成；切换等级移除旧造型及其独占材质。读取现有等级会重建对应外观。

验证：Unity 6000.3.23f1 编译并进入 SampleScene Play；实际观察基础汉堡柜台、Lv2 汉堡柜台及 Lv3 可乐柜台的造型区别。git diff --check 通过。本次为外观变更，未重跑全量测试，未进行 Android 构建。

体验入口：BurgerShop → Counter appearance preview (isolated save)。使用隔离的 5,000 金币存档，展示不同等级并开放西区；停止 Play 恢复原存档路径。尚未合并或推送 GitHub main。
