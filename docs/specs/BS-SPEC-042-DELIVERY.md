## 修订与实现

- 改正原方案的循环前置条件：先开放堂食及清理，再要求清理；先开放打包台，再要求加工蓝盒。顺序为基础订单、清理、员工服务、第二烤台、蓝盒、汽车、可乐、骑手、传送带，最后开放西侧纸袋区。
- Lv.1..9 晋级同时检查当前里程碑与星数；需求依次4/6/8/10/12/14/16/18/20，累计108星，扣除需求后保留余星。成功事件永久记账，首次奖励2星，不读旧累计售卖次数冒充新事件。
- 玩家/员工属性升级和餐桌首次选型增加2星，既有设施升级发星保留。没有改动041属性曲线、设施价格、生产间隔、基础订单单价、雇用人数或零件用途。
- Lv.10之后金币升级：500、750、1000……；每次增加基础现金的2%，所有经营现金经CashFloor统一应用，地上已有现金不重算，零件不加成。小额余数累计并保存。
- 左上角星级入口展示真实条件、解锁预告和缺口，复用现有升级面板；没有恢复中央任务胶囊。店铺不显示MAX，条件达成显示Ready。循环阶段更新招牌等级、颜色和加成文字。
- 新档按等级隐藏餐桌及其升级圆圈、雇用、设施购买入口、骑手区与传送带；可视验收发现的“桌子隐藏但投资圈仍在”已一并修复。

## 节奏契约六问

1. 服务比率时钟与开放回路：完成经营动作并攒齐条件后主动晋级。
2. 前段提供经营能力探索，后段提供现金效率和可见招牌变化。
3. 会改变T(n)。旧制只有6级，后续等级无T(n)可比；新制前段同时受目标完成时间与星源购买影响，不能简单用订单数换算。循环阶段若基础收入率为R，持币为C，理论攒钱时间为max(0,500+250*(r-10)-C)/(R*(1+0.02*(r-10)))；R及玩家实际耗时待实测。公式不是实测结论。
4. 没有增加倒计时或硬等待；逐级星源预算足够，但“等待是否有趣、是否低于90秒”仍需自然游玩验证，静态预算不证明手感。
5. 加成直接作用于已有经营现金产出，没有新增货币或孤立平行系统。
6. 店铺长期目标不以MAX或满条结束；不涉及广告/内购。现有其它设施MAX不属于本刀范围。
