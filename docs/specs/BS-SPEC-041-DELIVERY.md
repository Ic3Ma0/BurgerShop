## 节奏契约六问

1. 服务比率时钟：通过经营赚取升级成本，并改善搬运/行走效率。
2. 属于规模扩展，沿用原有动词与决策，不新增玩法系统。
3. T(n) 会变。若玩家当前余额 B、净金币收入率 R(n)>0，则静态估算 T(n)=max(0,Cost(n)-B)/R(n)。真实 R(n) 会受路径、订单及升级影响，未实测，不能输出秒数。相同收入率、零余额下：T(0) 原/新均为 50/R；T(4) 从 600/R 降至 100/R；T(10) 原来不存在，新为 260/R(10)；T(50) 两版均不存在。累计到第 10 级的 1170 金币不是实际耗时。
4. 不增加生产等待或解锁门槛；保留既有经营活动。20 级仍有终点，遵循本次 spec 的明确边界，不擅自无限化。
5. 无孤立系统；只改写已有升级成本、搬运容量与速度曲线。
6. I3 的“不用 MAX 收尾”与本次 spec 明确要求“20 级动态 MAX”存在例外：按用户确认的 spec 执行并记录；I7 不涉及。
