# BS-SPEC-015：扩店 1.5 倍、三档雇佣与员工清桌

- 版本：v1.0
- 状态：已实现（Editor EditMode 通过；未做 vivo 真机）
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-013](BS-SPEC-013.md) / [BS-SPEC-014](BS-SPEC-014.md) 之上
- 优先级与原因：用户批准扩店、三档雇员工、员工清桌；并追加硬数字：**整体空间扩大 1.5 倍**。
- 前置依赖：013 柜台/桌子/任务胶囊；014 用餐留垃圾与垃圾桶。
- 用户已确认：本刀已批准；场地必须按 1.5×，不要只「稍微加大」。
- 产品建议或关键未定项：三档价格仍按已雇人数计算。雇佣地点已被 [BS-SPEC-017](BS-SPEC-017.md) 改为 HR 房间；本刀写的主厅青色雇佣圈作废。

## 目标与范围

玩家目前是：20×20 地板上三桌、柜台、烤台、垃圾桶挤在一起；雇佣圈只雇 1 人（50 金币）；只有玩家清桌。

本次之后：店面按 **1.5×** 拉开；花 50 / 100 / 200 最多雇 3 名员工；员工继续汉堡循环，并会捡桌上纸团送到垃圾桶。脏桌整桌不能坐，清完才能再坐。玩家仍可自己清。

本次交付：

- 地面边长、围墙、玩家活动范围 = 原 `FloorSize` × 1.5（20 → 30）。桌子、柜台、烤台、垃圾桶、雇佣/升级圈、顾客队列的**间距**也按约 1.5 倍拉开。
- 雇佣档位：0 人→50，1 人→100，2 人→200，3 人满。每次在雇佣点停留约 1.5s 买 1 人，出去再进才能雇下一个。钱不够不能雇。地点见 [BS-SPEC-017](BS-SPEC-017.md)（HR 桌，不再用主厅青圈）。
- 员工：绿区取餐 → 柜台无限叠放 → 白圈出餐（共享烤台库存/柜台/收银冷却/钱包，不跳过 `servingInterval`）。脏桌有垃圾时去捡纸团（无限垃圾背包），再投垃圾桶。
- 任务胶囊可提示 `Hire a worker` 和下一个价格。
- 存档升版本；旧档 `workerHired==true` 恢复 1 名员工。

本次不做：

- 不改单价 10、烤台升级 30/60、手持 4、烤台库存 4、柜台无上限、吃饭 3 秒、每人 2 垃圾。
- 不引入 Pizza Ready 素材；不改摇杆位置/尺寸。
- 不回滚 014 纸团动画、整桌脏则不可坐、013 HUD。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` 组装。

| 项目 | 明确规则 |
| --- | --- |
| 场地 | 原地板边长 20 → **30**，墙 ±15。家具后来按厨房 / 柜台 / 用餐 / 南侧外送分区重排（见 `ShopLayout`），不再要求每件仍停在旧坐标 ×1.5。 |
| 雇佣 | 档位 50 / 100 / 200。停留 1.5s 扣当前档价格雇 1 人。必须离开再进入才能买下一个。最多 3 人。地点改由 017 的 HR 桌执行。 |
| 员工汉堡 | 与 013 相同：取餐 → 柜台 → 白圈出餐。多人共享库存与冷却。 |
| 员工清桌 | 桌上有可见垃圾时，空着手的员工走向该桌，按玩家同款拾取/投桶（无限携带、0.35s 飞行）。桌上清空后整桌可再坐。 |
| 任务 | 可负担下一档且未满员时，胶囊可显示 `Open the HR office` 或 `Hire a worker` 与价格（见 017）。脏桌/手持垃圾仍优先 014 文案。 |

建议循环：汉堡循环不变。雇人后员工自动送餐；有脏桌时员工会清，玩家也可清。

## 界面与资源

- 雇佣文案：未满员显示下一档金币；满员 `STAFF FULL` / `3/3`。呈现位置见 017。
- 任务胶囊：`Hire a worker · 50`（或 100 / 200）。不挡左下摇杆。
- 资源：运行时 primitive + `RuntimeMaterials`。禁止 Pizza Ready。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 钱不够 | 不雇、不扣款；提示还差多少 |
| 已满 3 人 | 圈内停留不再扣款 |
| 未离开再停留 | 本访只雇 1 人 |
| 旧存档 version 1 且 `workerHired==true` | 恢复 1 名员工；金币/成交/烤台/送单数保留 |
| 旧存档未雇人 | `hiredWorkerCount=0` |
| 新存档 | `version=2`，`hiredWorkerCount` 0–3，可选 `workerClears` |
| 垃圾 | 仍是会话状态，不存档 |
