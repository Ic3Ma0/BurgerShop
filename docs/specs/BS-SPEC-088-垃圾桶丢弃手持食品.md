# BS-SPEC-088 垃圾桶丢弃手持食品

用户发现先买可乐机、未买柜台时可乐占满双手导致无法继续卖汉堡。玩家靠近已有垃圾桶即可逐件丢弃手持汉堡/可乐，腾出容量；离开即停止新的丢弃。沿用垃圾桶范围与音效，提供飞入垃圾桶的反馈。无金币、星星或销售奖励。不处理盒装、纸袋等其他物品；员工原有倒垃圾流程保持不变。

## 技术边界与方案审查

- 归属与复用：TrashBin 控制靠近触发与节奏，BurgerInventory 仍唯一管理手持数量，复用 TryTake 与 TrashMotion 飞行动画。
- 状态归属：丢弃时从库存移交现有模型给垃圾桶动画，完成销毁，不复制食品。垃圾优先于食品；未进入范围、暂停或禁用不启动丢弃。
- 依赖方向：垃圾桶调用库存移交和展示音效，不调用钱包、订单或星星系统。
- 兼容与失败：无存档字段变更；已丢弃食品不退回，离开后已在途动画完成。销毁垃圾桶回收在途模型。
- 自动防线：汉堡/可乐清空、离开停止、暂停与范围、其他物品保留、取回汉堡恢复经营；原清桌垃圾回归。
