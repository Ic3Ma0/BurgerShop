# BS-SPEC-017：HR 房间雇佣

- 版本：v1.0
- 状态：开发中
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-015](BS-SPEC-015.md) 扩店 1.5× / 三档雇佣 / 员工清桌之上
- 优先级与原因：用户批准取消主厅青色雇佣圈，改为走进独立 HR 房间、在桌边停留雇人。
- 前置依赖：015 的 30×30 场地、50 / 100 / 200 最多 3 人、员工送汉堡与清桌。
- 用户已确认：本刀已批准；参考图只取空间关系（店侧开门、走廊进小房间、桌边雇人），不抄素材与商标。
- 产品建议或关键未定项：无。雇佣检测点从青圈挪到 HR 桌；档位沿用 015。

## 目标与范围

玩家目前是：在主厅青色地面圆盘（`StaffHiringSpot`）停留 1.5 秒按 50 / 100 / 200 雇人。

本次之后：主厅不再出现青色雇佣圆盘。店外侧有一间可走进的 HR 小房间；玩家进门、靠近办公桌停留约 1.5 秒，按当前档位扣费雇 1 人。雇满 3 人后不再扣钱。员工职责不变。

本次交付：

- 取消 `StaffHiringSpot` / `WorkerHiringZone` 地面青圈。主厅旧圈坐标停留不能雇人。
- 在 1.5× 店的东侧外墙开门，短走廊接入独立 HR 房（墙、门洞、办公桌、朝向桌子的椅子、简单电脑与架子）。门洞无碰撞，玩家能走进去。
- 雇佣交互点在桌附近。室内短英文提示下一档价格（`Hire staff` + 金币）。满员后不再扣款。
- 任务胶囊可出现 `Open the HR office`（尚未进过 HR 且能负担下一档）或 `Hire a worker`（已进过房间且未满员）。
- 占位几何 + `RuntimeMaterials`。英文可用 `HR`、`Hire staff`。

本次不做：

- 不改 50 / 100 / 200、最多 3 人、停留 1.5s、离开再进才能雇下一个。
- 不改员工送汉堡 / 清桌、玩家捡纸币、柜台无上限、3 桌、HUD 摇杆。
- 不引入 Pizza Ready / Kingshot / Doughnut 等名称、立绘或截图。
- 不改存档字段（仍用 015 的 `hiredWorkerCount`）。员工 Speed / Carry 升级见 [BS-SPEC-021](BS-SPEC-021.md)，不走本刀 1.5s 停留。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` + `HrOffice` 组装。

| 项目 | 明确规则 |
| --- | --- |
| 场地 | 主厅仍 30×30。HR 房接在东墙外侧，不堵柜台 / 桌 / 烤台。 |
| 门 | 东墙 `x = 15`、`z ≈ 0` 留缺口；无碰撞门洞，玩家能走进去。 |
| 雇佣 | 仅在 HR 桌附近（XZ 半径约 1.35）停留 1.5s。档位 50 → 100 → 200，最多 3 人。必须离开再进入才能买下一个。 |
| 旧圈 | 主厅原青圈坐标 `(0, 0.02, -8.25)` 不再生成圆盘，停留不能雇人。 |
| 任务 | 能负担下一档且从未进过 HR：`Open the HR office`。进过房间且未满员：`Hire a worker ·` 价格。脏桌 / 手持垃圾仍优先 014 文案。 |

建议循环：先赚钱，按胶囊走进 HR，在桌边停留雇人；员工仍自动送餐并清桌。

## 界面与资源

- 室内桌边：未满员 `Hire staff` + 下一档金币；满员 `Staff full` / `3/3`。
- 厅内可靠近门口的短英文 `HR` 指向门洞。不挡左下摇杆。
- 资源：运行时 primitive。禁止 Pizza Ready 素材与商标文案。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 站在主厅旧圈坐标 | 不雇、不扣款 |
| 钱不够 | 不雇、不扣款；提示还差多少 |
| 已满 3 人 | 桌边停留不再扣款 |
| 未离开再停留 | 本访只雇 1 人 |
| 存档 | 不新增字段；沿用 015 version 2 |
