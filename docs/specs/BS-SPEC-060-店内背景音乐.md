# BS-SPEC-060：店内背景音乐

- 版本：v1.0
- 状态：已实现，本地定向验证通过；未推 GitHub
- 用户确认：给游戏加上背景音乐
- 前置：BS-SPEC-028 的 Sound 开关与切后台停音

## 目标

进店后有持续、轻的店内音乐，让空档和走动不那么干。不改经营、不新增开关、不引入外部版权曲。

## 规则

- 开局自动循环播放；音量低于收钱/升级短音。
- 沿用现有 `Sound On/Off`。静音、切后台、失焦、`timeScale=0`（商城暂停）时暂停音乐；恢复后从暂停处继续。
- 本地合成循环乐段，不增加音频资源、不写入经营存档。
- `DecorationsEnabled` 关闭时不播。

## 验收

1. 新档 Play、Sound On：能听到循环店内乐，收钱叮仍更响。
2. Sound Off / 失焦：音乐停；再开继续。
3. 打开商城暂停经营时音乐暂停。

## 交付记录

- 合成约 10 秒 C–Am–F–G 循环（96 BPM，22050 Hz mono），峰值约 0.09，低于短音效源 0.18。
- `FeedbackDirector` 增加循环声部；同一 Sound 开关；后台/失焦 Pause，恢复 UnPause。
- Unity 6000.3.23f1，隔离工程 `/tmp/bs059-editmode`。`ShopBgmTests` 3/3 通过。未改真实存档，未推送，未做 Android。
