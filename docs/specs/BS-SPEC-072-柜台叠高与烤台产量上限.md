# BS-SPEC-072：柜台叠高与烤台产量上限

- 版本：v1.0
- 状态：已完成，本地定向 EditMode 通过；已纳入本地提交 `0e93618`
- 开发时基线（历史）：本地 `main` + 未提交 057–071；柜台沿用 061 不销毁模型；烤台等级仍 1–3
- 优先级：试玩希望柜台上的汉堡不断叠高、不要每 6 只换列；烤台待取堆要有按等级的产量上限
- 前置：061 柜台出餐手感（取出交还原模型、不销毁）；烤台 `ProductionStation` / `ExpandableGrill` 1–3 级
- 用户已确认：柜台数量无上限，每放一只就加高，优先单列向上叠；汉堡机 1/2/3 级待取上限 5/8/12，满则停产直到取走；第二台烤台按**自己的**等级用同一张表。不改 069 等级桌数、070 点击升级、068 槽位、071 走路（测试夹具若需库存数除外）、售价、可乐上限、restroom-ui、全局调价
- 产品建议或关键未定项：无

## 目标与范围

玩家目前把汉堡放到柜台后，超过 6 只会按 061 开新列，堆不成一根越来越高的柱子。烤台待取上限仍是旧表 4/6/8，容易在机旁堆满却看不出「这台机还能再出多少」。本次只改两处玩家可见规则：柜台无限单列叠高；汉堡机按等级封顶待取产量。

本次交付：

- 柜台库存无数量上限；每成功放入一只，该只的局部 Y 高于上一只；同一 XZ 柱，不再按 6 只换列
- 汉堡机（开局机与额外机各自独立）1 / 2 / 3 级待取上限 **5 / 8 / 12**；满则停止生产，取走后恢复
- 常量集中在烤台/工位，不写进 HUD

本次不做：改售价/客流/069–071 规则、可乐机上限、新存档字段、Android、卫生间 UI、全局调价、把柜台改成多列避屋顶（过高时仍叠高，镜头可裁切）

## 玩家价值与成长衔接

- 玩家当前已会烤、端、放到柜台再出餐。瓶颈是柜面「换列」不像叠汉堡，以及烤台待取没有按新表封顶。
- 现实里出餐台会把汉堡叠高；烤架上的成品有限，取走才继续煎。本作把柜台简化成一根柱，把「机上待取」做成等级缓冲。
- 不是新玩法：改写已有柜台布局参数和已有 `ProductionStation` 容量，不并列第二套库存。
- 不改升级价与售价；取走才腾出机位，玩家/员工搬运仍是出口（I2）。

## 经济与节奏依据

- 不改堂食/汽车/纸袋售价，不改烤台 30/60 与额外机升级价，不改烤制秒数。
- 只改汉堡机**待取缓冲**：Lv1 4→5、Lv2 6→8、Lv3 8→12。收入速度仍受烤制间隔、搬运和柜台出餐节流。
- 可乐机继续 4/6/8。升级 T(n) 不因本次改变。
- 柜台上无限堆货不增加金币，只增加可见库存。

## 玩家流程与规则

| 项目 | 明确规则 |
| --- | --- |
| 柜台放入 | 玩家或员工把汉堡放到柜台：计数 +1，留下原模型，按 `CounterStock.SlotLocal` 放到单列第 N 层 |
| 柜台布局 | `SlotLocal(i) = (0, i × LayerHeight, 0)`。无 `MaxVisible`、不销毁旧模型、不按 6 只换列。柱子再高也继续向上 |
| 柜台取出 | 仍取最上层那只交给出餐；倒进垃圾桶或从柜台出餐**不**改变烤台上限 |
| 汉堡机上限 | 常量 `ProductionStation.BurgerLevelCaps = { 5, 8, 12 }`。额外烤台用**自己的**等级查同一张表 |
| 停产规则 | 上限只约束该机**已完成、待取走**的汉堡（`ProductionStation.Stock`）。机台一次只烤一只。`Stock >= Cap` 时不再累计烤制、不会再完成下一只。`Stock < Cap` 时允许开始/继续当前这只；完成后 `Stock` 可以刚好等于 Cap。玩家可见：待取堆已有 Cap 只时烤台不再出新汉堡 |
| 恢复生产 | 玩家或员工从**该机**取餐位拿走一只，`Stock` 下降，生产恢复。柜台存货、出餐、倒垃圾不影响该机 Cap |
| 可乐 | 仍用 `ColaLevelCaps = { 4, 6, 8 }`，不改 |
| 文案 | 世界字保持 `GRILL n/cap`，满级可带 `MAX`；满堆不必另造 FULL |
| 费用 | 不改 |

## 边界、存档与兼容

不新增持久化状态。旧档烤台等级仍 1–3，读档后按本表设容量（可能比旧 4/6/8 多几个待取位）。允许 `LayerHeight` 沿用 0.22；过高超出镜头仍叠高。

| 情况 | 预期行为 |
| --- | --- |
| 柜台已很多 | 继续放入，全部可见，单列加高 |
| 烤台待取已满 | 停产；进度条停在满 |
| 从满机取走 1 只 | 可以再完成 1 只，然后再次停在 Cap |
| 两台汉堡机 | 各算各的 Cap，不共享待取数 |
| 可乐机 | 行为与上限不变 |
