# BS-SPEC-020：强化属性房间

- 版本：v1.1
- 状态：已实现（Editor EditMode 通过；未做 vivo 真机）
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-015](BS-SPEC-015.md) / [BS-SPEC-017](BS-SPEC-017.md) / [BS-SPEC-018](BS-SPEC-018.md) / [BS-SPEC-021](BS-SPEC-021.md) 之上
- 优先级与原因：用户已批准南侧强化房；本刀改为走进即弹出与 HR 相同的强化框，Speed / Carry 分档点击购买，并可点 X 不强化。
- 前置依赖：015 的 30×30 场地；017 / 021 HR 东侧房与员工点击升级框；016 纸币落地再捡。019 若并行增加 150 / 200 / 250 桌或机柜解锁圈，本刀不得占其厅内空位。
- 用户已确认：本刀已批准。取消「站 1.5s 同时升速度+携带」。禁止 Pizza Ready 素材。
- 产品建议或关键未定项：英文只用 `Boost` / `Training` / `Player upgrades` / `Speed` / `Carry` / `MAX`。不抄 Pizza Ready 房间名或素材。员工档位仍由 021 管理，**不与玩家档位共用计数**。

## 目标与范围

玩家目前是：移速开局 5.5、手持汉堡上限 4；东侧 HR 走进后弹出 `Staff upgrades`，点 Speed / Carry 立刻加员工属性。南侧强化房若仍用停留连升，和 HR 不一致，也无法只升一项或选择不强化。

本次之后：玩家进入南侧强化房范围即弹出同一套居中偏上强化框，标题为 `Player upgrades`。两个独立按钮：**Speed**、**Carry**。各 5 档，价格与 HR 一致。点一下：钱够则扣该档价格并立刻 +1 档；框可留着继续点。钱不够按钮灰；满级显示 MAX。右上角 **X** 关窗、不扣钱。离开房间也关窗。员工携带与移速不变。

本次交付：

- 独立房间（墙、门洞、训练/强化台）。门洞无碰撞，玩家能走进去。
- 进入强化房或南墙门洞即弹出 uGUI 框；复用 `StatUpgradePopup`。仅 Speed / Carry / X 的 `raycastTarget=true`。
- Speed / Carry 各 5 档，价格 **50、150、300、450、600**。点击购买，**不再** 1.5s 停留连升两项。
- 速度：以玩家开局 5.5 为基数，每档 **+15%**；满级 1.75×（9.625）。
- 携餐：开局仍 **4**；每档 **+1**，满级 **9**。只改当前操控玩家。
- 任务胶囊可出现 `Open the boost room` / `Upgrade carry`。
- 存档升到 version **5**；`playerSpeedTier` / `playerCarryTier` 0–5。旧档若已有 `boostLevel` N，迁移为两档都是 N。

本次不做：

- 不回滚 HR 房、1.5× 场地、纸币落地与放大、三档雇佣、柜台无上限、烤台 30/60、019 解锁圈。
- 不改 021 员工档位、HR 桌边 1.5s 雇佣。
- 不在主厅铺新的彩色地面圈（绿取餐 / 白收银 / 紫升级仍在原处；青雇佣圈保持取消）。
- 不堵 HR 东门、柜台、桌，以及厅内空边。
- 不引入 Pizza Ready / Kingshot / Doughnut 等名称、立绘或模型。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 按 `ShopLayout` + `BoostRoom` 组装。强化框挂在 `JoystickCanvas/SafeArea`。

| 项目 | 明确规则 |
| --- | --- |
| 场地 | 主厅仍 30×30。强化房接在**南墙外侧**（东侧已是 HR）。门在 `(11, 0, -15)`，偏东以避开西侧得来速马路。 |
| 门 | 南墙 `z = -15`、`x = 11` 留缺口（半宽 1.3）。无碰撞门洞，玩家能走进去。 |
| 房间 | 宽 8.2、深 8.2，中心 `(11, 0, -19.1)`。训练台 `(11, 0, -20.5)`。 |
| 弹出 | 玩家进入强化房（`ContainsBoostRoom`）或站在南墙门洞内（`ContainsBoostUpgradeRange`，含 `x≈11, z≈-15` 门缝）。 |
| 关闭 | 离开上述范围立刻关窗。点右上角 **X** 也关窗、不扣钱；仍站在房内则保持关闭，离开再进才再弹出。站在主厅或 HR 不弹玩家框。 |
| 购买 | 点 **Speed** 或 **Carry** 一次升该条 1 档。钱够则扣款并立刻生效。框不关，可接着点另一条或同一条的下一档。不再要求停留 1.5s，也不再一次同时升两项。 |
| 价格 | 档 0→1：**50**；1→2：**150**；2→3：**300**；3→4：**450**；4→5：**600**。与 021 员工价目相同，计数分开。 |
| 钱不够 | 该按钮灰、不可点、不扣款。另一条若付得起仍可点。 |
| 满级 | 该按钮显示 `MAX`，不可点。 |
| 移速 | 开局 `5.5`。公式：`5.5 × (1 + 0.15 × 档位)`。档 0–5：`5.5 / 6.325 / 7.15 / 7.975 / 8.8 / 9.625`。5 档 = **1.75×**。 |
| 携带 | 开局 4。公式：`4 + 档位`。档 0–5：`4 / 5 / 6 / 7 / 8 / 9`。只作用于当前操控玩家。 |
| 员工 | 携带与移速仍按 021 / 各自配置，不因玩家框改变。 |
| 任务 | 能负担下一项且从未进过房间：`Open the boost room`。进过房间且未满两项：`Upgrade carry`。脏桌 / 手持垃圾 / HR 雇佣提示仍优先。 |

建议循环：先赚钱，按胶囊走进南侧 Boost 房，点 Speed 或 Carry；也可点 X 离开。员工行为不变。

## 界面与资源

- 厅内靠近门口：短英文 `Boost` 指向门洞。室内墙面可用 `Training`。不挡左下摇杆。
- 弹窗：与 021 同一组件。居中偏上。标题 `Player upgrades`（HR 为 `Staff upgrades`）。左 **Speed**、右 **Carry**，右上角 **X**。按钮写名称 + 下一档金币或 `MAX`。
- 仅 Speed / Carry / X 的 `raycastTarget=true`；底板、标题、按钮文字及其它 Graphic 为 false。隐藏时 `blocksRaycasts=false`。
- 不新增主厅彩色地面圆盘。圈颜色用途不改（绿取餐 / 白收银 / 紫升级）。
- 资源：运行时 primitive + `RuntimeMaterials` + uGUI `HudChrome`。禁止 Pizza Ready 素材与商标文案。

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 钱不够 | 灰按钮，不升级、不扣款 |
| 已满 5 档（该条） | 显示 MAX，不扣款 |
| 点 X | 关窗，不扣款，档位不变 |
| 离开再进 | 框再弹出，两档保留 |
| 未点按钮只站着 | 不扣款、不升档 |
| 员工 | 携带仍按各自配置（当前开局 2）；移速不变 |
| 旧存档 version 1 或 2 | 玩家两档视为 0；金币、成交、烤台、员工保留 |
| 旧存档 version 3 或 4 且 `boostLevel` = N | 迁移为 `playerSpeedTier=N` 且 `playerCarryTier=N`；021 员工两档按原规则读取，不改写 |
| 新存档 | `version=5`，`playerSpeedTier` / `playerCarryTier` 0–5。不得改写 v3 / v4 checksum |

不存弹窗开关、X 关闭状态或玩家位置。允许开发自行决定的可逆细节：训练台占位颜色、门框厚度、室内小道具、按钮配色（不得改坐标与价格）。
