- 版本：v1.0
- 状态：已完成，本地定向验证通过；已纳入本地提交 `0e93618`
- 开发时基线（历史）：本地 main + 未提交 057–062

- 前置：045/046 门口与进店动线；061 柜台出餐

## 目标与范围

玩家目前能把汉堡递到柜前顾客手里，但最后一只交完后顾客会停住；排队或进店时还会穿墙。本次之后，订单收齐即离柜；堂食已开且有干净座位则沿店内不穿墙路线入座，否则经大门离店。从街道进店必须走现有南墙大门。

本次交付：

- 最后一只汉堡交接完成后顾客立即进入离柜（入座或出门）
- 进店、去座位、离店都不穿过实心墙
- 沿用 045/046 的 `RestaurantEntrance` 门口，不新建门

本次不做：改售价或客流、新存档字段、恢复 Serve/Waiting 条、Android。

## 玩家流程与规则

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 柜前顾客的本单最后一只汉堡飞到手上并结算 |
| 离柜 | 交接完成当帧即 `IsDeparting`；不得继续停在出餐位。堂食已解锁（店铺 ≥Lv.2）且有干净空位：沿店内路线入座（可先到桌边等待位）。否则沿大门离店 |
| 入座失败 | 座位满或桌脏：走到堂食等待位，不冻在柜台。店内寻路失败则改走大门离开 |
| 进店 | 从街道生成，路径为室外 → 转角 → 门口 → 店内入口 → 排队位。不得从西/南墙实体穿入 |
| 费用 | 不改 |

## 边界、存档与兼容

不新增持久化状态。旧档顾客仍用同一门口。允许开发选择店内绕柜台的具体途经点，只要不穿墙、能入座或出门。

| 编号 | 初始状态 | 操作 | 必须出现的结果 |

| AC-01 | 柜前顾客订单数量已齐（含多只最后一只） | 出餐交接完成 | 顾客 `IsDeparting`，离开出餐位；不冻在柜台 |
