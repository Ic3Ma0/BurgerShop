# BS-SPEC-050 现金堆高与摆放恢复

用户要求：钱随未领取金额向上堆高；修复 Done 后人物停滞。

现金：同一掉落点竖向叠放，较大单笔显示更厚的钱捆；最多展示四米高，超过后压缩显示但金额全部保留。优先取顶层，继续每 0.04 秒发起一次飞行，领取金额不变。

摆放：Done 恢复时间并清理预览后，下一帧重新失效寻路缓存、通知人物重规划，避免缓存旧碰撞布局。关闭/禁用商城也释放暂停。员工寻路失败必须停留在“前往”状态并重试，不可把原地当作到达工位。

调查：用户存档只读副本里的主通道与所有柜台排队入口可达，未复现所有人物同时停止，不能断言一定是隐藏界面。代码确认存在“无路线时使用当前位置作为完整路线”的错误，会让员工误进入到站状态。本次修复该路径及关闭后的缓存恢复。

不改价格、产能、存档；验收现金堆叠/精确入账、商城恢复时间及寻路刷新、员工原有工作测试。

## 验证结果

现金、员工、商城及关闭后的时间/路线缓存回归 43/43 通过。实际 Unity 渲染确认 20 次掉钱形成约 2.4 米高的钱堆；金额 200，连续领取后精确入账 200。隐藏每层重复金额标签。用户存档副本中的全员停滞尚未复现，需在用户实际购物流程观察；不把这项声称为已完全复现解决。原存档未修改。
