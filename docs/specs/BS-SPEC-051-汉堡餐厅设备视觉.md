# BS-SPEC-051 汉堡餐厅设备视觉

用户授权：结合本地玩法内核与真实设备参考，改进汉堡机、可乐机和柜台，符合汉堡餐厅风格；提出后续玩法方向。

## 本轮实施

- 汉堡机：不锈钢煎烤台、带把手的上压盖、肉饼、控制灯、出餐托盘。三档分别为单/双/三烤区，第三档增加排烟罩。压盖动画只跟随生产进度。
- 可乐机：独立的饮料机造型，带机头、按钮、出液嘴、接杯槽与滴水格栅。三档以出液嘴和选择按钮数量区分。饮料流动画只跟随生产进度。
- 设备升级不再双重放大为巨型方块。缩小视觉和对应实体碰撞，商城仍沿用保守的既有占地约束，因此旧摆放不会变成越界。
- 柜台：奶油色台面、品牌色饰条、收银屏、出餐托盘；打包台使用不锈钢工作面、备餐板、包装分隔架，蓝色仍用于蓝盒线路识别。
- 统一倒角轮廓；保留玩家操作点、升级价格、生产速度、容量、订单、解锁和存档。
- 收尾 049 的纸币/人物改动及验收。

## 验收

三档设备能看出用途和升级区别；汉堡与可乐设备结构不同；产物位于托盘上；移动、升级及存档逻辑回归；用 Unity 实际渲染检查设备和人物。旧测试中可乐应有烟囱/烤板的断言改为出液嘴/选择面板，汉堡升级断言改为多个压盖/排烟罩，其余交易数值断言保留。

本次是 L0 视觉反馈与可读性修改，不增加经济系统，不改变 T(n) 的标价或产出规则；实际经营耗时未测量，不给出虚构数值。
