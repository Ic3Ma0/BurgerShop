# BS-SPEC-036：自行车外卖与零件货币

用户确认：汉堡经过蓝色设备成为新的红色外卖包，搬到黄色取货台；自行车骑手排队取货，留下现金和独立零件货币；新增独立大区域。零件先只收集、计数、存档，不消费或兑换。

首版开发默认值（不是参考图精确参数）：北侧新增 30×17 区域，包含加工区和独立自行车道，直接开放蓝色设备及黄色取货台。1 个散汉堡→1 红包，加工 1 秒；原料/成品/取货台各容量 8，加工中占用成品容量；装卸间隔 0.35 秒，共用玩家携带上限。机器存料后自动加工，成品由玩家搬到取货台。其他食品不接受，不改变既有生产线。

骑手最多排队 3 人，每 8 秒补一人，按序停在黄色台外侧，每单 4 包，逐件交付 0.45 秒＋0.15 秒间隔。缺货等待，收齐才离开且只结算一次；每包现金 20、零件 1，地面掉落，由玩家靠近拾取。无堂食座位/垃圾/小费。自行车实际车轮、车架、骑手、后架和已交付红包可见。

零件余额为非负 long，溢出拒绝拾取。存档 v11 追加零件余额，v1–v10 校验不变，旧档零件为零。临时库存、骑手、在制品和地面掉落按既有现金/生产规则不持久化。暂停/失焦停止新线推进。

仅保留骑手图标＋剩余数量；零件余额在金币下方紧凑显示，首次获取前隐藏。无广告、兑换或新消费入口。本轮不增加员工自动搬运及新设施等级；后续可按 spec 补充。

验证：配方守恒/满仓、物品隔离、逐件交付与缺货、整单结算不重复、零件拾取与旧档校验、SampleScene 编译和实际 Play。Android 留待用户统一验收。

补充参考（两种骑手与道路）：普通两轮／绿色货斗拖车两种外观交替出现，共用红蓝头盔、蓝上衣、黄红车身；货斗型红包堆入绿色车斗，普通型堆在后架。两者订单和奖励沿用首版值，不从截图推断经济差异。黑色 EXPRESS 单向车道、浅色路沿、STOP 停车线、方向箭头和圆弯；路径与弯道共用坐标。只更新骑手及道路，不加入参考图的传送带、广告和其他界面。
