# BS-SPEC-091：纸袋工位商城外观一致

- 状态：开发中
- 用户已确认：实际外卖取餐柜台和纸袋打包台应与商城对应图片一致。

## 目标与范围

纸袋打包台保留深色台体和浅色分隔板；外卖取餐柜台保留商城中的深色台体，不再同时覆盖成奶白收银柜。纸袋机、红盒和蓝盒设备保持原样。
新购、重新摆放和旧档重建使用同一个原始造型。升级保留既有浅色等级饰条，不改变主体身份。费用、产能、订单、碰撞尺寸和存档格式均不变。

## 技术边界与方案审查

- 归属与复用：修复 BagLine.Register 升级回调中的错误通用柜台覆盖，复用 Model / BuildTable / BuildCounter 与已有 TierBars。
- 状态归属：设施等级仍由 GrowthUpgrades 与现有 BagLine 字段管理；无新增状态。
- 依赖方向：升级回调只更新等级及装饰，不让通用 CounterTierVisual 替换纸袋工位主体。
- 兼容与失败：旧档按原 ID 和等级恢复，重建即修正；不修改任何存档、经营或布局规则。
- 自动防线：比较商城无升级服务构建与游戏升级服务构建的主体网格、姿态和材质；验证恢复至三级后仍保留区别，重复恢复不堆叠饰条。运行 check-boundaries.sh。

## 验收

1. 一级取餐柜台和纸袋打包台分别与商城构建的主体一致，打包台有分隔板。
2. 二、三级升级及重复恢复不产生收银屏幕覆盖，保留等级提示。
3. 相关纸袋经营回归通过；手工 Play / 手机未执行时如实说明。
