# BS-SPEC-049 纸币与人物外观

用户要求：修复钱堆悬浮，地面钱堆、余额图标及收钱特效统一绿色纸币；人物从胶囊体改成有人形四肢的卡通角色。

实现：柜台掉钱高度从柜面降到地面；取消钱堆网格的额外高度差。用同一程序绘制的纸币图案替代密集细线网格，地面贴图启用 mipmap，减少远景闪烁。Coin 枚举保留兼容，其图案统一改为纸币，经济规则不变。玩家采用厨师帽、白制服；顾客保留衣服颜色，员工保留各自装饰和身份。添加手臂、裤腿、鞋子和随移动摆动的四肢。保留控制器、寻路、速度、携带挂点和存档。

验收：钱堆贴地且无待机上下浮动；纸币图标和飞行反馈一致；顾客、员工、玩家均有人形，相关交易和移动测试通过。本次不改经济数值。
