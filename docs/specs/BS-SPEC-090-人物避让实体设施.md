# BS-SPEC-090：人物避让实体设施

- 状态：已实现，定向自动验证通过，人工手感待复验；用户已确认所有人物不可穿过实体家具，摆放后立即绕行。
- 范围：玩家碰撞、顾客与员工导航、移动/新购设施提交后的障碍更新。保留现有经济、存档和工作分工。

## 行为与验收

1. 玩家移动被机器、桌椅等实体挡住，仍可沿边缘走开。
2. 员工与顾客绕过实体到达可用交互点；路径不通时等待，不能退化为穿过家具的直线。
3. 新购、移动、旋转设施提交后重新规划；不瞬移人物，不允许设施放在人身上。
4. 清桌、丢垃圾、取货和交付保持可达；保留库存与任务状态。
5. 验证旋转家具、圆柱障碍、动态布局变更、长帧及无路情况。场景人工试玩与自动测试分开记录。

## 技术边界与方案审查

- 归属与复用：复用 FacilityLayout 的布局版本和 LayoutNavigation；共享实体检测负责移动安全，角色原模块保留任务与队列。
- 状态归属：布局独占障碍缓存，角色独占当前路线进度；不新增持久化字段。
- 依赖方向：角色读取布局与物理实体；导航不修改订单、钱包和存档。
- 兼容与失败：旧档照常加载；失败保留人物位置并等待重试，不能用直线穿越作为兜底。交互目标在实体内部时使用外侧可达位置。
- 自动防线：定向 Unity 测试验证实体检测、路线分段、动态刷新和角色移动；执行 scripts/check-boundaries.sh。本轮不进行 Android 打包。
