# BS-SPEC-053 卫生间扩建

用户需求：增加卫生间扩展空间，顾客能使用。2026-09-14。

首版范围：大厅南侧 x=-5..4、z=-21..-15 独立房间，门通大厅，不占主入口或汽车区。入口修订：移入右上角超市首行，地面购买圈停用；Lv4 起可点击购买，300 金币（参照已有侧翼土地300），包括两个固定卫生隔间、洗手台。新价格/人数/使用时长集中 RestroomExpansion 配置；不改既有价格、门槛、升级、离线公式。

堂食完成后偶数号顾客尝试使用；最多4人（2隔间+2等候），满员则直接离店，不堵塞原餐饮流程。隔间独占，使用4秒、洗手1秒后释放并正常离店；关闭/销毁顾客必须释放占用。用户已确认：使用后变脏，需要玩家或员工清洁。每次使用后对应隔间停用、显示红色 CLEAN 提示；玩家靠近累计3秒清洁，已有可清洁员工会预约并走到隔间清洁。两间独立维护，队列等候超过20秒改为离店，避免强制无尽等待。无收费。卫生间固定建筑，不纳入可摆放营业设施地面。未解锁时商城显示 Lv4 提示、余额不足禁用，建成后显示 Built；旧圈投入抵扣剩余金额，固定建筑购买后直接建成、不进入拖拽。商城摆放不得阻断门外等候通路。暂停摆放时遵循现有Time.deltaTime暂停。

存档v16→v17，新增restroomBuilt、restroomInvestment、restroomDirtyMask，旧档默认未购买，保留v1..16校验和。使用中顾客/队列不持久化，脏污持久化。

验收：未购买门关闭；购买一次扣300、重复不扣；无余额不能完成；房间地面/墙碰撞连续；两隔间互斥；顾客吃完使用、洗手、离开；忙碌不堵餐厅；占用随顾客销毁释放；存档重开房间保持且旧档兼容；定向EditMode与本地渲染。Android不在本轮。

卡片版商城接入修订：卫生间为商品滚动区上方的固定购买条，不参与设施卡片过滤/排列。12级用户同样可见，已建成显示Built；响应式宽度随Catalog变化。
