# BS-SPEC-016：出餐与用餐掉落纸币，走过才入账

- 版本：v1.1
- 状态：开发中
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-013](BS-SPEC-013.md) / [BS-SPEC-014](BS-SPEC-014.md) 之上；可与 [BS-SPEC-015](BS-SPEC-015.md) 扩店/三档雇佣并存
- 优先级与原因：用户用附图批准「柜台上和桌边绿色纸币网格，玩家走过才捡」。
- 前置依赖：013 白圈出餐 / 桌子用餐；014 用餐留垃圾。015 若已合入则不要回滚场地 1.5×、雇佣 50/100/200、员工清桌、存档升版本。
- 用户已确认：附图即产品批准，不再二次确认。
- 产品建议或关键未定项：纸币用占位绿色网格，不要 Pizza Ready 贴图。

## 目标与范围

玩家目前是：白圈出餐瞬间 `RecordSale` 把 10 金币加进钱包，顶部金币 HUD 立刻跳数字。用餐结束只留垃圾，没有第二笔可捡收入。

本次之后：卖掉汉堡不再自动加金币。出餐在柜台旁掉 10 纸币；顾客吃完在桌边再掉 10 纸币。只有玩家走到纸币上/靠近才拾取并入账。成交次数仍在出餐时 +1。员工不吸钱。

希望解决：收入不像「地上捡钱」，出餐瞬间金币乱跳。

本次交付：

- 柜台出餐掉落 **10** 纸币（原来那笔成交款，只是改成捡钱）。
- 桌边用餐后掉落 **10** 纸币（新增可捡收入，不是第三笔自动入账）。
- 玩家 Trigger / 半径拾取；可多个叠在地上；一次捡附近一张或一叠；0.35s 飞向玩家再进账。
- 金币 HUD 只在 `Coins` 变化时跳；出餐不跳。捡到纸币入账时播一声合成金币叮（0.08–0.15s），出餐不响，见 [BS-SPEC-018](BS-SPEC-018.md)。
- 纸币是会话物，不写存档。未捡的钱重开后消失。

本次不做：

- 不改成交面额 10、桌边 10、烤台升级 30/60、雇佣 50/100/200。
- 不让员工自动吸钱。员工继续送汉堡/清桌（若 015 已实现）。
- 不升存档版本、不新增存档字段。
- 不引入 Pizza Ready 名称、截图、模型或商标文案。
- 不回滚纸团动画、柜台无上限、HUD、3 桌、扩店或三档雇佣。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装。纸币在出餐/用餐结束时生成。

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 白圈出餐成功 → 柜台旁（收银白圈 / 柜台桌面附近）生成 10 纸币。顾客吃完 → 该桌旁边生成 10 纸币，并仍留 2 个纸团。玩家进入纸币拾取半径 → 每次间隔至多捡 1 叠，纸币飞向玩家后再加金币。 |
| 费用 / 奖励 / 时长 / 上限 | 柜台掉落 **10**。桌边掉落 **10**。不再自动加第三笔。拾取间隔约 **0.25** 秒。飞行动画 **0.35** 秒（0.25–0.4 可测）。升级 30/60、雇佣 50/100/200 仍花钱包里**已捡到**的钱。 |
| 状态变化 | 出餐：柜台 −1，成交 +1，地上 +10 纸币，`wallet.Coins` 不变。用餐结束：垃圾 +2，桌边 +10 纸币，整桌仍不可坐。拾取动画结束：该叠消失，金币 +10。 |
| 与已有功能的关系 | 员工出餐同样掉柜台纸币，但员工不捡。玩家与员工仍共享烤台、柜台、收银冷却。脏桌整桌不能坐的 014 规则不变。 |

建议循环（写死）：

1. 烤台 → 绿区取餐 → 柜台放餐 → 白圈出餐（成交 +1，地上掉 10，金币不在此刻增加）。
2. 走到柜台旁纸币上，纸币飞向玩家，顶部金币 +10。
3. 顾客入座吃约 3 秒，留下 2 个纸团和桌边 10 纸币后离场。
4. 走到桌边捡纸币（+10）；清桌仍按 014。

## 界面与资源（涉及呈现时填写）

- 入口、显示位置、反馈时机：柜台掉落点在收银白圈靠柜台桌面一侧，世界坐标为 `ServingPosition + (-1.5, 1.12, 0.4)`（店内即 `ShopLayout.CounterCash`）。拾取半径约 0.85，站在白圈不会吸到。桌边掉落点为 `table.Center + (1.15, 0.04, 0.35)`，在过道一侧地面。多叠按 2 列网格向柜台内侧错开，避免站在白圈就吸到。拾取后飞向玩家约 0.35 秒，再进顶部金币 HUD。
- 正常 / 不可用 / 进行中 / 完成状态及文案：沿用英文 HUD。出餐不闪 `+10`；捡到才闪，并播合成金币音（018）。
- 参考图或布局说明：绿色纸币网格占位，像附图那样铺在柜台旁和桌边。摇杆与圈颜色不变。
- 资源交付：运行时 primitive + `RuntimeMaterials` 绿色薄片。禁止 Pizza Ready 素材；游戏内英文不得出现 pizza。

## 边界、存档与兼容（只写相关情况）

| 情况 | 预期行为 |
| --- | --- |
| 出餐瞬间 | 成交 +1，金币不变，地上有 10 |
| 未走到纸币上 | 金币不变，纸币留在地上 |
| 员工站在纸币上 | 不捡、不入账 |
| 多叠重叠 | 可叠；玩家经过范围内一次捡附近一张或一叠 |
| 切后台与重新进入 | 未捡纸币消失；已捡金币按现有存档保留 |
| 旧存档 | 不新增字段、不因本刀升版本 |

不新增持久化状态。允许开发自行决定的可逆细节：网格张数、拾取半径（约 0.85）、精确错开间距。飞行动画时长固定为 0.35 秒。
