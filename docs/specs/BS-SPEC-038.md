# BS-SPEC-038 打包与汽车售卖区视觉整理

用户要求修复蓝色包装机器处链板交叉，并参考图片的两个蓝色柜台整理汽车售卖区。

包装机内部改为沿 Z 轴直线贯通；入口、内部和出口同轴，两侧弯道在机器外部，圆角半径受短边长度限制，避免回折。保留现有自动生产规则。

汽车区保留后方打包台，改成长蓝台面、深色边框、蓝色抽屉柜，输入端有台面圈，另一端堆蓝色包装盒。前方售卖台与已有出货窗口合并为同一位置，删除重复的第三张台及高背货架，摆放真实包装库存和收银机。玩家/员工仍按原有打包、搬运、整单售卖规则操作；坐标与交互圈一起更新。汽车订单图标同步蓝盒，保持图标+数量的简洁 UI。蓝盒为项目原创蓝白几何纹样，不引入参考游戏标志或广告。

保留已有升级等级，以边框、金属饰条区分蓝色柜台等级；经济数值及存档字段不变。定向测试验证打包/售卖/运输及自动链，Unity 实机查看两处布局。Android 不在本轮。
