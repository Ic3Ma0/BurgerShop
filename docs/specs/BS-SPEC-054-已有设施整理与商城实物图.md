# BS-SPEC-054：已有设施整理与商城实物图

- 状态：已实现，本地定向验证完成
- 用户授权：已建好的设施可像购买时一样重新摆放；商城商品显示实体图片。

## 操作与范围

1. 右上角购物车打开商城，分为 `Buy` 和 `My facilities`。购买页只展示当前解锁商品，每张卡片包含实际游戏模型图片、名称、当前价格和购买入口。
2. 已有设施页列出可移动、已建成的经营设施，按种类编号，显示名称、图片与当前等级。与 BS-SPEC-055 的设施详情卡对接：点击卡片进入详情，选择 `Move` 自动定位该设施，进入现有摆放流程。也可选择 `Select in restaurant`，直接点击场景设施。
3. 桌椅、机器、打包台、柜台、取餐箱、垃圾桶使用同一移动、旋转、Done 流程；外墙、地块与固定房间不作为可移动家具。
4. 移动预览期间隐藏原模型，取消恢复原位；Done 成功后恢复模型并保存位置。库存、升级、已付费进度、桌面状态与服务点随原实例保留，不重买、不复制。
5. 手机拖动调整、松手固定、点 Done；桌面沿用用户认可的鼠标摆放方式。UI 操作不拖动模型，非法位置保持可调整并说明原因。编辑暂停经营，退出恢复时间与寻路。

## 图片与性能

使用现有实际模型生成目录缩略图，图像作为本地资源缓存。打开/滚动商城不创建生产实例，不扣款、不修改单例和存档，不持续运行额外相机。图片表示该类设施的购买外观；已有设施另标当前等级，点击后的 3D 预览使用该实例的实际外观。

## 兼容与验收

- 不改价格、解锁、产能、占地校验或存档格式；沿用既有布局记录。节奏经济参数与 T(n) 不变。
- 基础设施和商城追加设施均能从列表选择；未建造或未开放设施不出现在已有列表。
- 原设施取消不改位置/金币；移动旋转后服务点与状态正确，保存重载不重复生成。
- 15 类商品均有实际图片；手机竖屏与桌面横屏卡片不溢出，列表能滚动。
- 定向 Unity 测试覆盖交易、已有实例搬迁、原档布局恢复、UI 点击不漂移、退出恢复；实际渲染查看商城与摆放。

Android 与 GitHub 发布按用户后续安排。
