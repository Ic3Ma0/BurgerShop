# BS-SPEC-083：小店轮廓、顾客行走与中文提示修正

- 版本：v1.0
- 状态：已实现，待用户试玩复验
- 用户已确认：本轮四张试玩截图；直接修复，无新增经营系统。

## 目标与规则

1. 新档营业面积缩为约主厅的三分之一，机器、柜台、两张后续开放的桌子与操作点靠近。墙体只沿当前店面边缘搭建；未买的土地为室外草地，不显示完整大院。沿用 Lv3、150 金币扩建及 +2 星，扩建后外墙向外移，设施位置保留。
2. 每名顾客使用固定但不同的步速、道路横向偏好及转弯半径；共享服务队列仍先来先服务。门口收窄、互相让行，不能穿墙、逆序或叠在一起。身体朝向跟随实际位移，转弯路径在可通行范围内圆滑过渡；不随机摇摆。
3. 左上任务使用短中文、字号 14–20（通常为 19–20）、自动换行且不越界。星条只显示等级、星数与可点击的升级状态；去掉重复任务描述。推荐投资仍显示真实价格、实际收益、星数和缺款。

## 边界、存档与兼容

- 不调整价格、星门槛、收入、生产或服务冷却，也不添加房间或产线。
- schema 18 → 19，新增小店布局标识。v18 及更早存档保留已用的空间和全部摆放；未扩建的 v18 也移除外围大院墙。新档用更紧凑布局，扩建后仍保留其设施坐标。切档不共享布局标识。
- 中文使用随项目分发的开放许可字体，不依赖开发机系统字体。

## 技术边界与方案审查

- 归属与复用：MainHallExpansion 管地块边界，ShopLayout 管默认设施点；复用现有扩建付款及摆放校验。顾客路径整形独立于 CustomerQueue 的服务顺序；中文显示适配器不写成长状态。
- 状态归属：地块/布局标识由 MainHallExpansion 唯一持有、Persistence 保存；排队进度由 CustomerQueue 持有；每人外观仍由 082 模块负责。
- 依赖方向：入口读取存档布局 → 地块与默认位置；队列/顾客调用路径帮助类；HUD 只读现有报价和任务。显示与视觉不得修改钱包、订单、奖励。
- 兼容与失败：旧布局完整保留；路径平滑需验证通行，失败退回原路径；跨档重置布局状态。沿用现有事务保存，不新增付款入口。
- 自动防线：新旧布局/扩建/切档回归；排队顺序、行走方向及路线差异断言；中文字符和 UI 几何检查，横竖屏渲染复核；执行 scripts/check-boundaries.sh。

## 验收

- AC-01 新档为紧凑小店，周围只有草地；扩建后墙体与地板一起扩展且原设施不移动。
- AC-02 v18/v17 档空间、设施及进度保留，新旧档互切恢复各自布局。
- AC-03 多名顾客进出门路径存在稳定个体差异，前进与身体朝向一致；不破坏先来先服务和最小间距。
- AC-04 左上提示全部短中文，星条没有任务说明；横竖屏均在框内，推荐投资保留价格/收益/差额。
- 真实 0–15 级节奏、移动自然程度由后续用户试玩复验；自动测试不能替代主观体验。Android 验收不在本轮。
