# BS-SPEC-018：工位升级反馈、数字跳动与金币音效

- 版本：v1.0
- 状态：开发中
- 对应基线：已验收 MVP **0.1.2**，叠在 [BS-SPEC-013](BS-SPEC-013.md) / [BS-SPEC-015](BS-SPEC-015.md) / [BS-SPEC-016](BS-SPEC-016.md) / [BS-SPEC-017](BS-SPEC-017.md) 之上
- 优先级与原因：用户已批准增强反馈：烤台逐级升级要看得见、顶部与柜台数字增加时 punch、捡钱有金币音。
- 前置依赖：013 HUD / 柜台；016 纸币落地再捡；015 扩店与三档雇佣；017 HR 房。
- 用户已确认：本刀已批准，不再二次确认。
- 产品建议或关键未定项：无 Pizza Ready 素材。音效用代码合成短 AudioClip，不从网上下载版权音。

## 目标与范围

玩家目前是：烤台升级只改 `ProductionSeconds` 和两盏小灯；金币/星星/柜台/任务数字瞬间替换；出餐已不再自动加钱，但捡纸币也没有「叮」一声。

本次之后：LV1→2→3 每次升级都能看出升了一级（短震动/放大、多一块烤台部件或等级灯、`LV2`/`LV3` 弹出再落下）。满级停在静态 `MAX`，不再跳升级。金币、星星 `n/15`、柜台份数、任务进度在数值**增加**时短放大再回弹。玩家捡起纸币（或金币数增加）播一声短金币音；出餐本身不加钱因而不响。升级/雇佣扣钱用同一套降调短音。

希望解决：升级像改内部数字、HUD 数字发死、捡钱没反馈。

本次交付：

- 烤台每次停留购买仍只升 1 级（30 / 60）。升级瞬间：工位短震动+放大、等级灯/额外炉面出现、`LVn` 弹出再落下。
- 满级静态 `MAX`，圈内再停留不跳升级、不扣钱。
- 可复用的工位升级反馈；当前只有烤台可升级。
- 顶部金币、星星 `n/15`、柜台份数、任务进度：增加时 punch（约 0.2–0.35 秒），可用 `Advance(deltaTime)` 测。金币增加可从旧值滚到新值。花钱轻微闪一下，不用大红报错。
- 捡纸币入账或 `Coins` 增加时播 0.08–0.15 秒合成金币叮声。出餐不响。一次捡钱只响一次。

本次不做：

- 不回滚 HR 房、1.5× 场地、纸币落地、纸团、三档雇佣、柜台无上限。
- 不改 10 / 30 / 60、雇佣 50 / 100 / 200、每次停留只买 1 级。
- 不引入 Pizza Ready 名称、截图、模型、UI 或商标文案；不从网上下载版权音效。
- 不升存档版本、不新增存档字段。读档恢复等级时不播升级动画。

## 玩家流程与规则

入口：`SampleScene` Play 后由 `Goal01Bootstrap` 组装。烤台仍走紫色升级圈。

| 项目 | 明确规则 |
| --- | --- |
| 触发条件 | 升级圈内停留 1.5s 且付得起 → 升 1 级并播工位反馈。金币/星星/柜台/任务数值增加 → 该数字 punch。玩家捡起地上纸币、飞行结束入账 → 金币音。`TrySpend` 成功（升级/雇佣）→ 降调短音。 |
| 费用 / 奖励 / 时长 / 上限 | 升级价与产能不变。Punch **0.28s**（允许 0.2–0.35）。金币叮 **0.08–0.15s**。弹出字约 0.8s 内落下。满级 3，不再升级。 |
| 状态变化 | LV1：无额外炉面。LV2：1 盏灯 + 1 块额外炉面，弹出 `LV2`。LV3：2 盏灯 + 2 块炉面，弹出 `LV3`，留下静态 `MAX`。读档只显示当前等级部件，不弹出。出餐：成交 +1，金币不变，不响。捡钱：金币 +10，响 1 次。 |
| 与已有功能的关系 | 016 纸币与 013 HUD 仍有效。员工不捡钱因而不触发金币音。玩家与员工仍共享烤台/柜台/收银冷却/钱包。 |

建议循环（写死）：

1. 捡到 30 金币（叮、金币数字 punch）。
2. 走进紫色圈停留 1.5s：扣 30（降调短音、金币轻微闪）、烤台放大一抖、亮灯/多一块炉面、`LV2` 弹出落下。
3. 离开再进、付 60：同样反馈到 `LV3` + 静态 `MAX`。再停留不再跳。
4. 之后出餐只掉纸币；走到纸币上飞入后再叮一声，顶部金币跳动。

## 界面与资源（涉及呈现时填写）

- 入口、显示位置、反馈时机：升级反馈挂在烤台本体。等级灯沿用蓝色小灯；额外炉面是烤台上多出来的占位热板。`LVn` 为烤台上方 TextMesh，弹出后落下并消失。`MAX` 在满级后一直留在烤台上。HUD punch 作用在金币字、星星 `n/15`、任务底部进度、柜台徽章数字。
- 正常 / 不可用 / 进行中 / 完成状态及文案：升级中弹出 `LV2` / `LV3`（英文数字）。满级 `MAX`。金币增加可短暂 `+10`；消费 `-30` / `-60` 用浅金闪，不用红色。
- 参考图或布局说明：不挡左下摇杆。圈颜色不变（绿取餐 / 白收银 / 紫升级）。
- 资源交付：运行时 primitive + `RuntimeMaterials` + 代码合成 AudioClip（正弦+少量方波）。禁止 Pizza Ready 素材；游戏内英文不得出现 pizza。

## 边界、存档与兼容（只写相关情况）

| 情况 | 预期行为 |
| --- | --- |
| 同一次停留 | 只升 1 级，只播一次升级反馈 |
| 已满级 | 静态 MAX；不扣钱、不放大、不弹 LV |
| 读档恢复 LV2 / LV3 | 灯和炉面按等级亮着；不弹字、不震动 |
| 出餐 | 不入账、不播金币音 |
| 捡一叠纸币 | 入账时金币音 1 次；HUD punch 1 次 |
| 花钱 | 降调短音；数字可轻微闪/punch，不红屏 |
| 切后台与重新进入 | 沿用现有存档；会话纸币与 HUD 动画不存 |

不新增持久化状态。允许开发自行决定的可逆细节：炉面颜色、弹字高度、音高具体赫兹（时长必须落在 0.08–0.15s）。
