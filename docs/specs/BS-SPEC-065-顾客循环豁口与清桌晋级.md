# BS-SPEC-065：顾客循环、墙体豁口与清桌晋级

- 版本：v1.0
- 状态：已完成，本地定向验证通过；已纳入本地提交 `0e93618`
- 开发时基线（历史）：本地 main + 未提交 057–064
- 优先级：Play 中顾客卡门/卡柜/不入座；核心厅仍有豁口；Rank 2 清桌后不能晋级
- 前置：042 双门槛；061 柜台；062 开局胶囊；063 进门离柜；064 开局不含附属房
- 用户已确认：新档大厅除正门封闭；顾客必须进门、取餐、入座或在桌边等待且不得冻住；清完桌必须能晋级。不改全局经济、不恢复 ActionHint、不回退 061/062/064
- 产品建议或关键未定项：无

## 目标与范围

玩家当前在 Play 里仍看到：顾客卡在门口或墙里、汉堡齐了还停在柜台、有空净桌也不走去坐；核心厅东/南各留一个豁口；Rank 2「Clear a used dining table」清完后胶囊 1/1、星星不够、不能 Rank Up。

本次之后：新档核心厅是封闭盒子，只留南墙顾客正门；店内有一条始终可走的室内路由（正门走廊，禁止 null 当冻住）；清桌完成当前级必做动作后即可晋级（星星够 `CanUpgrade`，胶囊切到 Rank Up / Lv.n Ready）。

本次交付：

- 统一室内走路：`ShopLayout.Walk` 始终返回可走路径；过南墙只走正门；绕柜台走 z=0 过道，不穿柜体
- 关着的 HR / 汽车厢门洞必须有实心封板（Play 下开关同一帧也不得拆掉封板）；开对应等级后再开门
- Rank 2 清桌在「桌面垃圾被收走」时记账，并补足本级晋级所需星星

本次不做：改售价/客流/StarCap 公式、恢复 InteractionFocus/ActionHint、回退 061 柜台垃圾外观、062 左胶囊与开局、064「到级才出附属房」、Android。

## 玩家价值与成长衔接

- 玩家当前阶段：Rank 1 升到 Rank 2 后进入堂食+清桌。证据：用户 Play 报告清桌后卡在 2/6 且 1/1 胶囊无法晋级；顾客循环断裂导致清桌目标本身也难完成。
- 现实餐厅：客人进门、取餐、入座、离席留垃圾、店员清桌。本作简化为一条不穿墙的店内路线 + 一次清桌即完成 Rank 2。
- 新决策：无新玩法。修的是既有循环的死路（I2/I8）：清桌不能变成「目标完成却不能升」。
- 解锁：Rank 2 清桌是雇人前最后一关。此时玩家未必已买够属性星，Rank 1 烤台升级会顺带给星，清桌没有对应付费升级。
- 对经济：不改价格。只在 **CleanTable 且为当前级里程碑** 时把星星补到本级 `StarCap`，使双门槛在这一级不会卡死。其它级仍按 042。

## 经济与节奏依据

- `ShopRanks.StarCap(2)=6`，`RecordMilestone` 只 `AddUpgradeStars()` +2。042 假定星星来自属性/设施升级；Rank 2 刚开堂食，清桌动作本身不花钱，玩家可以 0 星进本级，完成后停在 2/6。
- 不改 `StarCap`、不改升级价。局部补星等于提前发放本级本应可从已开放来源攒到的星，只解除死路。
- T(n) 不变（设施价不变）。本级从「无出口等待」变为可点 Rank Up。

## 玩家流程与规则

| 项目 | 明确规则 |
| --- | --- |
| 进店 | 街道 → 转角 → 正门 → `Entrance` → 排队。身体不进入墙体实心。不得从 HR/Boost 豁口穿入 |
| 出餐离柜 | 本单最后一只汉堡交接完成当帧 `IsDeparting`，离开出餐位。1 只或 2 只订单相同 |
| 入座 | 堂食已开且有干净空位：先到该桌等待位再入座。座位满或桌脏：到等待位，不冻柜台。寻路失败则改走正门离开，禁止站着不动 |
| 室内路由 | `ShopLayout.Walk` 是唯一顾客室内路由器。`FacilityLayout.Route` 失败或穿墙时回退 `IndoorRoute`。返回值永不为 null/空 |
| 墙体 | Rank&lt;3：东墙 HR 门洞实心封上。Rank&lt;5 且未买打包/车道：南墙 Boost 门洞实心封上。正门保持开口。到级后打开对应门 |
| 清桌 | 玩家把桌面垃圾收走（桌面 `TrashCount==0`，或成功拾取）即记 `CleanTable`。若本级目标就是清桌：星星补到 `StarCap`。停在 Ready 等待点击，见 SPEC-070（066 自动升已否决） |
| 费用 | 不改 |

## 界面与资源

- 任务胶囊：开局结束后，本级目标完成且可晋级时标题为 `Tap Lv.{n} Ready`，进度 1/1。左上星条沿用 `Lv.n Ready`
- 界面语言：英文
- 封门墙与主墙同样高、同样厚，并按主墙刷表面，不得留下深色缺口

## 边界、存档与兼容

| 情况 | 预期行为 |
| --- | --- |
| 干净邻桌 | 必须走向干净桌，不得在脏桌或柜台冻住 |
| 重复清桌 | 里程碑只记一次，不重复发星 |
| 只倒垃圾未拾取 | 以桌面变干净为准；拾取成功也记账（先拾取即完成） |
| Play 下先开门再关门（同一帧） | 封板必须仍在；禁止 `Destroy` 延迟导致门洞空一帧后永久缺口 |
| 旧存档 | 不新增字段。已达 Lv.3/5 的档进门即开对应房 |

不新增持久化状态。绕柜台的具体途经点只要不穿墙、能入座或出门。

## 验收标准

| 编号 | 初始状态 | 操作 | 必须出现的结果 |
| --- | --- | --- | --- |
| AC-01 | 新档 Rank 1，或 `Allows(3)=false` 且 `Allows(5)=false` | 看核心厅 | HR 门洞与 Boost 门洞有实心封板（`Physics.CheckBox` 挡住）；正门仍开 |
| AC-02 | 上述门洞已封 | 升到 Rank 3 / Rank 5（或已买打包） | 对应门打开，房间可用 |
| AC-03 | 柜前顾客 1 只或 2 只订单，食物已齐 | 最后一只交接完成 | `IsDeparting`，离开出餐位 |
| AC-04 | 堂食已开、有干净座位 | 同上 | 沿室内路线走到座位并坐下；过程不进墙体占用 |
| AC-05 | 新客从街道进店 | 走到队首 | 路径含正门；身体不进入墙体实心 |
| AC-06 | Rank 2，目标 CleanTable，桌有餐后垃圾 | 拾取（必要时再倒掉）使桌面干净 | 里程碑已记；星星达到本级 `StarCap`。停在 Ready，点击晋级见 SPEC-070 |

不应破坏：061 柜台飞出、062 左胶囊与开局只指升级、064 到级才出附属房、042 其它级双门槛、经营数值。
